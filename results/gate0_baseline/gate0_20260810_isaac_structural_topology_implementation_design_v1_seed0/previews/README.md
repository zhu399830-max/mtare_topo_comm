# Preview provenance

Every preview must record split, world, trajectory/sample ID, method, units, and the hypothesis it supports or contradicts.

This run produced no scientific preview because it was a design and read-only audit run. Creating a decorative world, topology, point-cloud, or learning-curve image would falsely imply generated or measured evidence. The first permitted preview is the one-world common-geometry and fixed-pose Isaac/Gazebo parity panel after explicit execution approval.
