# 独立绕数检查：20条射线穿过重叠内部后才离开

执行`tools/v3/inspect_synthetic_invalid_returns.py --winding`，只读原封存4观察中20条无效射线。全帧重渲染0，新标签0，退出码0。新增独立三角面立体角求和模块`mesh_winding_diagnostic.py`；四面体内外、反向、重合两层、平移与表面拒绝测试2项通过（0.07秒）。测试只验证数值诊断，不是科研验收。

在原相交距离之间的中点，对全部approach三角面求定向立体角总和。分别使用原double网格与实际float32网格，以及对应坐标精度。没有使用生产器的正负法向分组或它的最终标签作为答案。

20条结果均为近整数，两个精度版本的整数序列完全一致：

- 7条：1→2→1→0；
- 12条：1→2→1→2→1→0；
- 1条：1→2→1→2→1→2→1→0。

1表示一层内部，2表示扫掠网格重叠覆盖，0表示外部。所有中间区间均非零，最后一个交点后才为零。椭圆例在6.474794/6.475433/6.481274米三个交点间呈1→2→1→0，因此最近交点不是外边界。原1cm混合法向组保留bool inside，遗漏了最后真正离开。

该证据支持“现有交点状态机不足以处理原扫掠网格内部重叠”的系统诊断，不能证明该折叠mesh等于理想光滑地下表面，也不是机器人可通行证明。此工具只检查approach的绕数；没有把它推广为任意多operand场景的已验证求交算法。

下一修正限定为显式可选的重叠多重度/外边界处理，并先覆盖内部重叠、普通单层、共面重复三角形、相切、分离通道等合成回归。不能简单累加重复面，不能任意缩分组容差，不修改旧默认或封存结果。只有完整来源与外边界对应通过，才讨论新版本的局部纠错；原矩阵4控制不追认，99未评分仍保留。
