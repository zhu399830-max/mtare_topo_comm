# 共享候选学习读出软件

实现 `representation/gse_candidate_readout.py`，复用现有 `_MessageLayer` 的128维、三层稀疏消息传递，不新建骨干。最多4096面片＋496轴对候选，每候选保留8邻居槽；超限报错，不截断。输出固定候选位置、存在性logit与有效掩码，不做位置回归、NMS或建图。

A读取128维局部观测特征和当前三维坐标；B增加18维面片属性；C进一步使用9维关系。沿用既有面片特征格式，不把真实身份当输入。A也共享几何候选，不是几何无关系统。参数布局一致；C的邻居计算量更大，不能因此声称计算成本完全匹配。

6项测试通过（0.71秒）：A隔离显式几何、B隔离关系、C对关系有响应；三组排列对应、固定位置和有限反向梯度；非法邻居拒绝；前向不接受targets且观测特征不反传到旧编码器。软件测试不证明真实生产路径不存在泄漏，生产候选和特征来源仍需绑定。

当前没有训练更新、真实特征重提取或新的感知成绩。下一接线封存候选与已有紧凑观测缓存，明确轴对候选的几何字段掩码和邻居含义，不能给没有法向的轴对填造法向。随后固定独立训练目标、完整负背景和输出去重评分：只算正例分类准确率无效；固定位置和置信度筛选不能静默删除未命中锚点。训练仍需新精确规格和资源检查，旧失败模型不扩训。
