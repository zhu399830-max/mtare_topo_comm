## 为什么2米可能影响骨架

1. `voxblox/src/integrator/esdf_integrator.cc:186`附近：非固定带的新体素初始化为默认距离，本批为2m，同时parent清零。
2. 同文件`:386`附近：距离达到最大范围的体素不继续传播；`:430`附近只有能降低邻居距离时才写入障碍来源方向。
3. `voxblox_skeleton/src/skeleton_generator.cpp:129`附近：parent为零的体素跳过，不进入骨架候选。

因此，空旷区域即使有观测，也可能缺少本算法需要的障碍来源方向。该机制为配置可能导致中心骨架缺失提供解释，但**并未证明真实307图中的每个断裂都是2米截断造成的**。当前结果只保存最终图与边采样，不含完整距离场及各阶段排除计数，不能事后精确重建原因。

五帧观察下的遮挡和稀疏表面也是另一个可能因素。没有控制变量实验，不能把二者混为一个已证原因。

## 不改变研究合同的处理

- 保留307结果、原图、照片式点云预览和所有失败证据，名称明确为“官方核心／五帧／2米距离范围的候选骨架诊断”。
- 暂不进行原生骨架与学习路口的优劣排名；几何点不是语义节点，自连接也不是已穿越边。
- 不直接复制未知占据壳：那会改变本项目未知语义，不是单纯优化参数。
- 不通过2m、3m、5m等开发集搜索挑选最好分数，也不修改旧run。

可行选项：

1. 推荐先做固定合成条件的因果检查：同一通道几何、同一批扫描，仅比较已有2m与上游有来源的5m距离范围，记录已观测但无parent体素、中心区域骨架及最终分量；原未知规则和其他参数保持不变。只证明范围机制，不作为新研究胜出结果。若有必要扩大真实人口，另登记范围改变，不能冒充原run补跑。
2. 完整复制官方地图示例：需要改变地图积累范围和未知处理，不再是当前五帧同输入比较，成本更高，不作为立即下一步。
3. 直接自写degree聚类映射路口：缺少真实支路归属与可观察性依据，会引入另一个未验证算法，不采用。

本问题属于基线配置／系统接口，不是数据泄漏或模型训练失败。受影响的是非学习上限与语义优劣结论，而不是源哈希、307执行记录或R0/R1/R2历史训练成绩。当前只读审查完成，无新训练、扫描读取或积分。

## 与论文主线的关系

这项工作只为了建立可解释的几何参照，不能无限扩成新的骨架方法。学习主线仍需证明：相同观测和后端下，面片几何关系能减少漏路口、错分支及错误关联。现有分组实验没有完成显式关系消融；没有公平语义输出接口就不拼排名表。合成范围检查结束后必须给出参照适用性结论，再回到结构输出和独立关系贡献，不继续围绕图变漂亮调参。
