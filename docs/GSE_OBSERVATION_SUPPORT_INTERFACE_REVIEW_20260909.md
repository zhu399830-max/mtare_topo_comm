# 观测证据接口：复用什么，不把什么当成功

## 当前判断

关系对照没有满足扩训条件。此处只核对现成接口，不新训练、不新增真实数据、不改保存预测。仅靠射线网格拒绝部分候选，不能证明几何关系模型的创新，也不能修复已确认支路召回下降。

## 实际可复用代码

- `representation/gse_surface_ray_evidence_v1.py`：五帧首返回与相对位置形成固定0.25米网格，保存自由、占据、未知及各帧支持位。网格分辨率已有合同，不按本轮结果调整。无效射线不贡献证据，范围外回波不能被裁成假表面。自由只说明有射线经过，不保证整个体素或机器人包络可通过。
- `representation/gse_surface_observed_inputs_v1.py`：输入仅为观测XYZ、有效性、帧槽和射线原点，复用上述网格与面片间射线证据，不需要构造身份。
- `data/development_grid_export.py`：可校验并读取已冻结的三数组观测网格，避免重新积分所有射线。数据来源绑定必须由外层完成。
- `data/development_reference_grid.py`：生成网格本体只用student，但封装调用了教师参考认证；不直接作为部署入口。
- `evaluation/development_paired_scoring.py`：其coverage涉及bundle、构造参考、目标记录。它是独立评分工具，禁止拿来筛选部署预测。

## 必须分开的三个问题

1. 点附近是否有观测：射线网格能够提供有限证据。
2. 此处是否为真实结构路口：需要分支组合与跨帧一致性，不能由自由状态推出。
3. 两个位置是否连通并可安全行驶：需要轨迹、配准和局部执行检查，不能由模型方向或局部自由证据推出。

因此，不能把候选中心所在体素为自由当作节点确认条件；真实路口中心也可能未被激光充分穿过，未知必须保留而不是误判不存在。模型输出的方向没有独立开口位置，不能擅自沿方向取一个距离伪造验证点。

## 下一软件动作与限制

复用原网格的数值边界处理，增加独立、只读的候选位置观测证据适配：输入仅观测网格和预测XYZ，输出相邻体素状态、帧支持位及边界歧义；不接教师、不改变候选坐标、概率、数量或评分。空网格、面/棱/角边界、范围外和上下分层作为合成检查。先证明观测证据不会泄漏真值或制造确定性。

之后才绑定原保存预测与相同307观测网格，检查该观测证据和已保存未知标签之间的关系。该分析只回答“是否缺观测支持”，不自动过滤候选，不挑拒绝阈值，不训练。若缺少足以确认结构的支持，候选只能维持未确认状态；要成为图贡献仍必须经过统一后端和独立图对照。不能以工程拒绝策略代替原几何学习主张。
