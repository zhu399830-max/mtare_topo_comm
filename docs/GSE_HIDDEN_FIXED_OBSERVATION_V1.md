# 隐藏构造对照：固定观测，独立验证几何排除

## 为什么修改检查定义

上一版分别渲染原地图和删支路地图，15条距离出现最大2.384e-7m差异，bitwise相等断言失败并保留。没有改射线或加容差追认该断言通过。

本轮先证明被删除支路是否接触原记录观测，然后采用“同一固定观测、不同不可观测构造”的反事实定义。该定义变化依据下面的几何排除证据，不是为了改名获取PASS。

## 独立几何结果

`gse_recorded_segment_exclusion.py` 对原float64与float32的mesh坐标包络构造保守AABB，对记录射线段的端点采用向外舍入区间。某个坐标轴严格分离才算排除；相切、穿过、边界不稳定、无效返回均不被认证。无任何新距离阈值。该检查不调用标签程序。

原hidden_branch/circle/view0五帧、57600条记录段全部排除，0未证明；删除mesh范围约x[7,30]、y[14,18]、z[-2,2]，最小分离轴间隔11.244440737米。7项区间/排除单元测试0.11秒通过。

它证明的是这些记录射线段与该有界mesh的隔离，不是任意真实传感器噪声下等价、全世界物理安全或两次渲染的逐比特一致。

## 固定观测完整标签链

`remove_unobserved_hidden_operand` 验证原构造、指定case和位姿，重新计算全部段的排除。只删除名为hidden的指定源；如果其参与任何实际返回，拒绝操作。其余几何逐项保留，教师来源代码按剩余ID重编码；模型的四个student数组始终逐元素不变。明确记录原/控制构造SHA及证明摘要。

实际合成代码 `check_gse_hidden_counterfactual.py` 通过：

- 原/控制student完全相同；局部record完全相同。
- 两者均0锚点、2开口，没有给不可见远支路补确定答案。
- 错case和无效返回两个篡改拒绝。
- full_training_gate_eligible仍false。

只执行一个固定观察的代码检查，不是12配对或144主用例全通过，也不是新的真实标签或训练。

## 后续范围和计数

144主观察仍需渲染720帧出现；12控制将复用对应60帧的固定student观测，执行额外12次构造/标签对照，而不是再生成60个不同距离图。总计156个标签评价条件，720个主扫描帧出现。此前780是独立双渲染方案的计划数，现明确替代，不混报。
