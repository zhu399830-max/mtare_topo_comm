# 尽头漏检定位：回波层间隙被硬过滤

只读复算固定 `terminal__circle__view2`，沿用封存面片诊断卡中原扫描SHA及相同默认参数。1个五帧观察，57600回波、600面片，其中576个法向有效；无训练、无标签修改。

最近的有效线面交会证据如下：

- 轴线与面片513的平面交点约 `(6.000000, 0, -0.018735)` 米。
- 法向与轴方向绝对点积约0.9999997，不是平行退化。
- 面片包含51个回波，五帧支持分别为5/7/13/13/13。
- 面片下方回波的最高z约-0.104730米，交点与其外接框距离0.085995米；上方面片最低z约+0.104730米。
- 传感器代码的垂直角为-15到15度、步长2度，包含±1度而没有0度。6米处 `6*tan(1°)≈0.10473` 米，与实际回波空带相符。

所以该例端面有观测，法向和交点位置也合理；旧选择条件要求无厚度轴线穿过单个小面片外接框，恰好落在两层回波之间时全部拒绝。不能由此推断其他17例原因相同，亦不能把层间无回波区域直接声明实心。

软件增加 `distance_to_patch_bounds_m` 连续特征，不改旧within_patch_bounds逻辑，不加接受距离阈值、不改变原成绩。新增稀疏间隙反例连同已有面片测试19项通过（0.41秒），间隙保留0.1米且不声明整通道封闭。

下一考虑直接保留原始面片中心作为观测候选，并与轴对候选并列评分：先在同45人口测其覆盖、总数和多余候选，不依赖无限平面补洞。面片中心是实际观测位置而非结构中心，仍需要后续学习定位/筛选；中央路口保留轴对候选。该比较尚未执行，须冻结新规格。当前完整节点训练继续暂停，不重训旧模型。
