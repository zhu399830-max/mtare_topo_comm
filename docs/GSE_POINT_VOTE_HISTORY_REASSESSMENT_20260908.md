# 旧点云投票实验：哪些能复用，哪些不能重跑

## 已核实的实验

来源是 `gate3_20260905_gse_point_axis_probe_v1_seed0` 及其只读证据恢复 `gate3_20260905_gse_point_axis_evidence_v1r_seed0`，位置均在 `results/gate3_semantics/`。使用 C01 的10个父地图、180个五帧观察、900个帧出现次数、1452个可见片段。两组各540更新，共1080更新。不是独立泛化成绩。

| 读出 | 每观察平均坐标MAE（米） | 控制点平均欧氏误差（米） |
|---|---:|---:|
| 旧冻结模型 | 3.612 | 8.271 |
| 原始点坐标的学习加权，无学习偏移 | 1.780 | 4.111 |
| 点坐标加学习偏移后再加权 | 2.826 | 6.102 |

带偏移组在10/10父地图都比无偏移组差，原决定为 `STOP_BEFORE_EXPANSION`。原实验最后绘图报TypeError，仍为SYSTEM_FAIL；后续证据恢复没有重训，也没有把原运行改成成功。

关键纠正：`raw_no_offset` 不是非学习估计器。`configure_variant` 只冻结两个偏移层，其余点权重、成员竞争和特征模块仍然训练。不能用它作为“非学习基线”宣传学习增益。

## 现有成绩没有证明什么

`gse_point_axis_probe.py` 明确仅训练几何，额外查询保留但不计算检测误报。每种输出均有4308个未匹配查询，不能把该数直接称为4308次实际误建图，也不能因匹配误差改善就宣布检测成功。

独立的 `gate3_20260905_gse_axis_observation_dependence_v1r_seed0/metrics/summary.json` 中，无偏移组的无向轴方向误差约16.85度，横向RMS约2.34米。打乱观察与输出对应后坐标MAE增加约3.44米，只表明输出包含观察对应信息；无法排除位姿相关性和拟合记忆。它不是对输入点云做受控干预的因果实验。

因此：旧点级特征和坐标加权运算值得保留，旧权重可作受限几何对照；旧轴线裁剪端点不可升级为三维开口，旧投票头不作为已经合格的结构候选器。

## 执行决定

不新增旧投票训练、轮数或种子；不再开展另一轮自由查询纠错。先明确观察驱动候选的几何覆盖能力，再决定学习筛选是否有意义。候选阶段必须同时记录覆盖率、位置误差、每观察候选数量及直道背景；仅覆盖到真值、却产生任意多候选不算通过。

下一步为复用现有射线/局部几何软件，制定同一封存合成人口的候选比较接口：只从观测产生候选，真实锚点只评分，不能从教师中心播种。先检查软件是否已有可用的观测空间峰值或局部空隙提议。若没有，明确新增实现而不是把教师proposal改名。开始新数据依赖计算前冻结规格，不改变45观察的旧成绩。

本轮新增模型推理、训练更新、读取原始扫描均为0。此次判断缩小了可复用范围，但不证明几何关系学习原理失败，也不改变最终论文目标。
