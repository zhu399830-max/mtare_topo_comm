# 自动窗口开口候选：首版规则与边界

2026-09-07，纯软件/合成实现，真实人口尚未执行。

复用已有原网格截面、有限射线穿越和0.25米表面格支持。不重新训练网络，不将内部构造端面当局部窗口开口。

对固定10米球域的轴线交点处截面，只有以下两项同时存在才标记proposal_supported：

1. 沿窗口外向方向、在首次返回前穿过截面内部的射线，其返回具有唯一且匹配的来源。
2. 同一来源的返回支持至少一个截面轮廓格。

多来源或未知返回不能选一个便利来源；反向穿越不算向外开口证据。没有要求整个轮廓完整。保留具体射线索引、来源帧及已观察／参考格数量。

这是预先声明的**候选规则**，并未验证为可靠语义教师。输出位置/方向明确叫reference，宽高、锚点及归属不生成，qualified_labels仍为0、training_eligible=false。一个边界格和一条射线可能很弱，不能把该规则当作通过人工复核、可通行或完整节点检测的替代品。候选需在既定真实范围验证错误情形及覆盖，再决定哪些字段有资格成为损失目标；当前不得直接转换为正式训练标签。

9项组合合成测试通过，包括部分边界、没有边界、其他/未知来源、反向穿越和内部切面拒绝。首次正例恰落在原格边界，因此按原规则无确定表面支持；修正测试几何避开该数值歧义后通过，未修改格判定或容差来制造正例。

下一步绑定既有30观察作一次候选诊断：各源候选必须共同检查竞争，不能将逐源候选视为最终去重开口。真实标签、训练和模型成绩仍为0，旧run及图片不动。
