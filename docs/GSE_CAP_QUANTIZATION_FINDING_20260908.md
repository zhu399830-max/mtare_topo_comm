# S07入口见证存在量化引起的方向翻转

## 直接证据

对原封存四观察使用相同mesh .05m/64和原打包射线，以NumPy双精度线性方程求解射线/三角形交点；不调用Open3D求交器或标签生产器。逐条核声明的尽头端面、相反入口端面、三角形索引、first-return前方及法向方向。

四观察共41,639条尽头见证、6,635条入口见证（S07两候选共享见证，只计一次）。在原单精度几何上，全部位于相应三角形内部，尽头方向为离开、入口方向为进入。与原返回距离的最大重算差约2.96微米；没有选择新容差作为标签验收。

然后以量化前的原mesh顶点、原双精度传感器位置和方向计算同一端面平面的交点参数：

| 观察 | 入口见证数 | 原双精度平面参数范围/m | 单精度正交点但原参数非正 |
|---|---:|---|---:|
| S04 mixed36237 | 1696 | 0.000333966—0.000419156 | 0 |
| S04 ellipse36237 | 1887 | 0.000333966—0.000428579 | 0 |
| S04 rounded_rectangle36237 | 1696 | 0.000333966—0.000419156 | 0 |
| S07 rounded_rectangle97000 | 1356 | -2.1768111244739584e-14—-1.5503330448368874e-14 | **1356** |

S07的单精度重算最小入口距离为8.917098713567813e-7米。原始几何实际上处于端面数值边界，所有声明的向前进入都是量化后才获得正参数。不能把微小负值解释成具有物理意义的“在端面后方”，但足以否定“进入方向已稳定证实”。399个t的单精度ULP并不等于巨大米级误差，实际绝对差仅约2.97e-11米；关键是世界坐标量化改变了接近零的交点符号，而非求交器大范围算错。

## 对结论的影响

S07两条负归属仅依靠cap_entering路径，没有source-interior/outgoing备选，因此**当前观测否定依据未通过资格**。这不证明其拓扑参考关系本身为真或假，也不表示模型失败。旧结果保持FAILED和原标签，不静默改写。

S04三个变体没有该方向翻转，但仍是同一父地图/同一结构的相关观察；不能把它们视为足够的负例人口，也未完成连续段独立资格。此前“来源一致”结论仍成立，但明显不足以证明几何见证可靠。

新增不依赖真实数据的斜端面量化反例：原交点非正，打包float32后交点为正且确实位于三角形内。它证明“重算原float32交点在三角形内”不是观察充分性的完整标准。13项数值/来源篡改测试0.11秒通过，实际只读工具两次均退出0。
