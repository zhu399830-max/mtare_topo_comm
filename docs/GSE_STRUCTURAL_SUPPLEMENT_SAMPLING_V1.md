# 补充结构采样：规则与实现

## 解决什么问题

原3360观察按边抽样，开发样本只有5个路口和5个尽头空间参考，尚不足以形成可信训练与评价人口。保留原数据，不重造地图；新增面向结构的采样层。只用C01–C07，沿用60拟合父地图及C07原5校准/5开发分区。

## 本轮固定规则

1. 覆盖库存全部结构候选：拟合414路口/385尽头、校准35/31、开发32/29，共926实体。degree=2构造分段不冒充语义节点。实际可见性仍待核实。
2. 每实体以种子20260906及稳定SHA排序固定一条具有五帧历史的incident有向穿越。先选穿越、后读取位姿；不查看预测分数、点云可见程度来换方向。
3. 在这条穿越的合法决策位置中，选择三变体中最大锚点距离最小的位置；距离使用原始三维sensor位姿和各变体构造锚点。相等时取源序列ID较小者。三变体始终取同一源序列，不各自挑位置。
4. 任一变体距离超过既定10米仍保留记录，标注范围缺口，不另选方向凑有效人口。距离接近不等于看见；TNG候选不直接成为标签，也不进入模型候选查询。
5. 原3360观察完整保留为未筛选背景层，背景并非负标签；仍须观测支持/完整区域判定。结构层与背景层重合时只导出一次输入，保留全部采样身份。不同实体或几何变体不冒充独立父地图。

这是用户已授权补样方向的具体实施规则，替代新增层继续受每父16边限制的假设，不改变旧批次。源位姿只作离线采样及坐标绑定，不作为模型额外输入。

## 数量和数据卡边界

若926实体都有可绑定原始位姿，将有2778个结构观察请求，加原3360请求共6138；这是去重前上限，不是已选出的有效样本量。分区上限为拟合5277、校准438、开发423。唯一输入数、五帧去重数、涉及位姿块及实际间距须由精确清单编译器计算后绑定新数据卡和run spec。

本轮只实现无文件读取的选样函数并执行合成软件测试；未导出真实补充观察，未读取新位姿/扫描，未生成教师或启动训练。本文是采样规则，不冒充已批准的精确数据读取卡。正式数据操作仍须冻结源文件哈希、精确行/块清单并通过预检，沿既有范围授权执行，无需重复一般批准。
