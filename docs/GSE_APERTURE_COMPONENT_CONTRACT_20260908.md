# 开口实例接口：参考、几何连通与观测支持已分离

新增`aperture_component_contract.py`：输入边界单元的明确邻接和FREE/BLOCKED/UNKNOWN状态，分别输出几何自由分量、观测自由分量、可能经未知区域连接的分量对及冲突单元。参考截面只在分区后作多对一对应，不进入连通计算。相邻关系必须由后续几何适配器提供，本模块不会凭参考ID或距离造邻接。

未知桥不强行合并，也不宣称确定分离；完整地图的隐藏连接不能把两个观测片段强行变成一个有观测证据的标签。几何/观测冲突显式保留，训练资格始终false，不能把这个软件接口当成合格教师。

## 实际完成的测试

离散接口8项：多参考同实例、分离区域、三开口、未知桥、隐藏连接、证据冲突、单元置换、非法邻接。

另新增`aperture_spherical_boundary.py`，不是只做抽象连通图：八面体细分4级得到2048个三维球面三角单元，共享边构建邻接；解析径向圆管在球面形成球冠。通过三角单元的覆盖角范围判断整单元自由或阻挡，边界无法确定则unknown，不以中心点取值代替整个单元。

4项三维测试通过：重叠径向圆管1自由分量；同方位上下分层2分量且不确定关联为空；T形3分量；重复/重排基元状态完全一致；另检查整单元角界内的确定重心组合点。合计12项通过，0.25秒，无新扫描/标签/训练。

## 范围限制

当前只验证解析径向圆管的合成几何适配，不是原99条件已经重新评分。偏移轴线、椭圆/超椭圆、弯管、原mesh和五帧观测到整单元证据的适配均未完成。三维测试中的observed_state全部unknown，不伪造可见性。whole-cell角界是数值几何诊断，不是物理安全证书。

下一统一扩展到有限直管及偏移多边形截面的整单元几何范围判断，优先覆盖原重叠反例和分层/平行情况；不能将原弯管擅自替换成直段并宣称几何不变。保留独立观测适配缺口，未建立来源和覆盖依据前不生成新教师或启动训练。
