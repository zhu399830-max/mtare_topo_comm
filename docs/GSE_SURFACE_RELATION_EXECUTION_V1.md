# GSE-Graph 面片关系执行规格 V1

状态：用户2026-09-07完整批准；实施中；没有新面片模型研究成绩。
权威入口：PLAN.md；当前范围Phase3/Gate3。旧软件、权重、结果与论文图片均保留。

## 唯一研究问题与贡献边界

在相同五帧因果LiDAR、相对运动、位姿与图后端下，面片组合是否使开口、稳定结构锚点及实际穿越连接更准确？
面片图/GNN、拓扑通信、配准本身不是新贡献。主要证据必须是C去掉关系后感知/图收益消失，而不是软件能运行。

- Superpoint Graphs：https://arxiv.org/abs/1711.09869
- BoxMap：https://arxiv.org/abs/2410.06263
- TravExplorer：https://arxiv.org/abs/2605.19958
- RAEM：https://arxiv.org/abs/2608.25366

## 方法与接口

五帧观测+相对运动→原坐标特征/表面面片→关系学习→三维锚点和开口→跟踪/配准/实际轨迹→结构图。

1. 复用冻结五帧编码器和点级适配接口。教师、世界/节点/边/traversal身份、绝对世界pose和未来帧不进入模型前向。
2. 确定性体素局部分组与PCA；固定局部10m范围，初始面片体素边长0.5m作为软件默认并写入独立配置，不按真实分数调节。低支持/退化面片保留并标低可靠性；不以教师选面片。容量4096，超限显式失败。保持射线穿过ROI而在外返回的自由证据，不能把裁剪点当表面。
3. 面片属性：中心、法向及可靠性、范围、粗糙度、点数、五帧支持；关系：相对位置、方向、高差和同源射线自由/障碍/未知证据。k=8近邻是消息邻居，不是物理可通行边。
4. 模型128维、3层关系消息传递，观测旁路始终存在。不作全点两两注意力，不展开全人口重复高维点特征。A观测/B观测+面片自身属性/C加面片关系；B/C匹配可训练规模并报告计算量。
5. 版本化观察保存来源帧/明确顺序、机器人坐标、32锚点位置/存在/不确定性、64开口位置/方向/有依据尺寸/观测支持、三态可通行、锚点开口的非强制单归属关系与有效掩码。空/未知不能填伪几何。
6. 移动ROI开口不能直接触发物理节点；独立锚点query预测真实路口/尽头位置。普通构造分段不是结构节点。不训练地点身份、旧707事件分类器、策略或通信网络。
7. 短时3D跟踪和持久节点坐标分开；跨访问合并需要配准、开口及轨迹证据。不同片段显式断开，片段内逐个相邻锚点连边。预测根可达不替代local planner或实际穿越证据。4m是评分合同，不是合并半径。

## 教师与标签

物理参考：同几何实现的collision/support，多层地面状态，机器人包络、坡度、台阶及邻接转换。不能在3D空气里flood-fill。实际URDF和部署参数/源码含义只读绑定一次；sensor height或maxIncl拟合限不得冒充车身或通行能力。

观测支持：仅同五帧真实射线及相对运动；首返回前自由/返回表面/其他未知；地面只能在实际支持的局部邻域拟合，不跨层、跨遮挡补地面。这是固定离散工程代理，不是连续空间安全证明。

- 正：有观察支持的候选路径，物理参考确认通过。
- 负：有观察支持的障碍、断地、坡度/台阶违例，不是搜索失败或隐藏GT障碍。
- 未知：支持不足或参考冲突；禁止当负例。
- 稳定锚点：TNG/spline仅供loss/评分；只有本五帧支持相应分支或真实终止时监督。ROI裁剪不是端墙，成员存在不等于连接。
- 人工复核真实发生前只称自动标签诊断，不伪造review结果；主模型成绩须披露标签来源/有效覆盖。

## 三个有限先行检查

1. 合成一次验收：直道/T形/近邻双路口/堆叠/尽头/遮挡/窄缝/坡道/断地；同观测不同隐藏地图不能有矛盾的确定标签；移动窗口不造双节点；零跨段边、前缀一致；理想输入完整恢复可支持结构及相邻连接。
2. 固定真实teacher pilot后才全批导出。fit可达开口/可观察不可通行开口/锚点各至少20独立实体及5父；dev各至少10及3父。仅排除空任务，不代表统计可靠。保留物理路径/观察支持/原始与复核标签和理由。
3. 新fit固定32有效观察、最多500updates；锚点/开口F1均>=.90，锚点匹配误差<=1m，完整可评分区域多余预测计FP。loss下降不能代替验收；失败仅一次定位修正。

## 配对训练及评价

首轮seed0，各2000updates，AdamW lr.001 wd.0001，microbatch1×累积4。共同冻结编码器、初始化、样本顺序、标签、输出头和图后端；仅新适配/结构模块训练。A也继承既有几何预训练。不新增几何拟合/描述子/一致性loss。初始和final全量评价，不选best。各loss按有效目标独立归一化，匹配不看语义/置信度，未知不作负例。

GPU28GiB、主机32GiB、三组训练及评价12h、新证据30GiB；实际吞吐先测，不套旧头速度。CPU与GPU并行但正式冻结源运行期间禁止代理编辑绑定文件。

主比较C-B，辅助B-A，另报同输入非学习几何、旧出口、旧扫掠通道；旧异合同分数不得混表。C对A/B/同后端非学习的开口、结构节点、结构边F1分别>=+5pp；节点相同3D锚点4m主评并报1/2m敏感性；报告开口位向尺寸、可通行、未知、错合并、漏分支、重复节点与确认距离延迟。按父图配对CI，变体不伪作独立父图。

软件测试/理想输入/小样本拟合均非方法成功。单种子实际图收益成立才加seed1/2；均报告、至少2种子满足主线且均值收益成立。独立穿越只报告片段结果；真实连续记录才评价回环、全局图/探索。当前不自动读取未见地图或启动闭环。

## 已批准的有限备案

每类最多一次，所有额外诊断修正合计24h。触发前报告具体证据，触发后记录研究主张变化；无重复常规批准，不静默修数据/降线/改分母。

|触发|唯一处理|结论边界|
|---|---|---|
|机器人包络/旧pose支撑无法绑定|停物理标签，继续面片/开口/软件|不宣称地面可通行|
|五帧根可达有效人口不足|收缩为可见开口+局部截面通行，抵达由local planner确认|不宣称完整root connectivity|
|自适应面片不稳定|固定体素面片，三组统一重冻结|不按样本改提取参数|
|32/64目标溢出|训练前一次容量翻倍并资源检查|再次溢出停止，不截断GT|
|理想输入图失败|只修一次图后端|不重训感知掩盖|
|32观察拟合失败|理想几何交叉替换定位，一个有证据修正|再次失败停止扩训|
|B优于A但C无增益|冻结输入一次关系移除/破坏诊断|不宣称组合创新|
|感知好图不好|真/理想交叉替换决策链|不调planner补成绩|
|锚点持续不稳定|定位anchors+学习开口系统保底|撤回学出结构节点主张|
|图好探索无增益|报告无增益，停止多机|通信文件小非探索成功|
|泄漏/漂移/评分错|停止受影响结果，独立版本纠正|不覆盖原证据|
