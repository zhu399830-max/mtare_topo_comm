# 观察轴线的三维关系候选

## 为什么做这个接口

复核 `RobustPrimitiveRelationBaseline` 发现，它已经从五帧扫描与相对运动拟合三维轴线，但 `both_ego_stubs` 条件会直接设置attachment。新候选诊断不消费这些连接标签，也不消费构造身份，只复用拟合几何。

新增 `representation/gse_axis_pair_proposals.py`。每对有效轴线以首尾弦近似直线，求三维最近点对。中点是未验证的候选位置，同时输出两线距离、方向关系、数值条件、超出已拟合段的距离及中间控制点偏离弦的程度。所有数值可供后续观察特征/面片关系读出比较使用，但当前不训练、不筛选、不建图。

最多32条轴线，全枚举最多496对，不按教师或模型分数选对；平行和退化对保留未知状态。这个上限来自已有基元接口，不是32节点模型的输出容量，不得直接向32查询检测器塞入496条候选并静默截断。

## 不能宣称的内容

两条上下分层通道的最近点中间可能在空气中，因此中点不是确定路口。分离距离必须保留，不能只看XY交叉。曲线弦近似和长距离外推也不可靠。直道只有一条轴线时无交点；本接口不检测尽头，也不把裁剪端点当尽头。这是交汇关系候选的几何对照，不是完整结构感知方法或新的论文主张。

7项新软件测试与8项评分测试联合通过：15 passed in 0.20s。覆盖交叉、分层、平行、外推、共同旋转平移及反向/排列、退化、全部枚举及容量失败。分层例保留4米分离，未被标为连接。软件通过不等于真实观测拟合轴线准确。

## 后续同输入诊断

下一固定45封存合成观察的运行规格：原扫描及因果相对运动→默认非学习轴线→全部三维轴对候选→独立1/2/4米覆盖评分。读取真值仅评分，记录每例轴数、候选数、未知数和外推/分离，不以真值选择子集；尽头无候选应如实记漏检，不删除该类。用途是确认该候选对照是否有研究价值，不以此替代学习方案。若几何提议本身无覆盖，不启动学习筛选训练。
