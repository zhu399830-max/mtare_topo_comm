# 块内点云编码接口已实现，尚未训练

上一轮发现：把超点仅当作一个中心和法向，会抹去其内部墙面布局。本轮将原始点真正接入共同编码接口，体素面片和超点可以使用相同的软件，而不是比较两种不等价的输入。

## 输入和计算

`gse_block_points.py`保存全部原始当前传感器坐标、五帧索引、点到块映射、中心和真实观测范围；不丢小块、不复制点补数量、不接受负归属。上限沿用单观察57,600点、4,096块和10米范围。

`gse_block_point_encoder.py`对每个点输入当前坐标、相对块中心偏移、按块观测范围归一化的局部坐标和五帧来源。两层逐点线性/GELU编码得到128维特征，再按块最大池化。真实中心、范围、退化标记另外保留。零范围的点块不伪造物理尺寸；块中心不是表面点或节点。

这是PointNet式的共同软件部件，不是完整SPG复现，也不是新的结构检测成绩。没有加载或训练新权重；当前随机初始化只用于接口与梯度测试，尚未接入旧冻结编码器特征、锚点、开口预测或图。

分批计算使用同一个最终分块归约，避免分批最大值合并导致重复点的梯度分配不一致。保留单观察N×128特征，因此训练内存仍随点数增长；不声称分批使训练内存恒定。没有全点两两注意力或全人口逐点特征展开。

## 实际验证

18项联合测试通过，0.84秒，覆盖点顺序与块编号置换、单批/分批输出及参数梯度（包含重复点）、空输入、单点/退化块、相同中心不同空间布局，以及容量/范围/负归属失败。

5090 D最大合成输入软件检查已完成：

- 57,600点、4,096块，输出4,096×128；18,432个参数。
- 分批2,048点，前向与反向约0.185秒；全部参数梯度有限。
- 峰值GPU分配241,820,672字节，约231MiB；进程峰值内存1,268,563,968字节。
- 优化器更新0、真实研究观察0。耗时不含输入构造，不是端到端学习或探索吞吐。
