# 成熟实例聚合机制：能借鉴什么，接入前还缺什么

本次阅读官方源码，不安装第三方库、不读取新扫描、不训练。新增的只是监督接口检查，不是新模型成功。

## 1. VoteNet并不是给每个表面点独立打一个中心分数

其投票模块用种子点特征预测三维偏移及残差特征；随后在投票空间分组、聚合局部特征，再预测目标存在性和中心残差。这样表面证据可以指向没有回波的目标中心，而不是要求中心必须落在某个面片上。[投票模块](https://raw.githubusercontent.com/facebookresearch/votenet/main/models/voting_module.py)、[聚合与候选模块](https://raw.githubusercontent.com/facebookresearch/votenet/main/models/proposal_module.py)。

但它需要投票监督。官方ScanNet读取器按实例点集合构造中心偏移和有效掩码，损失仅对有效目标点计算投票误差。我们不能把“有27个锚点坐标”当作已经有了这些点级答案。[数据读取器](https://raw.githubusercontent.com/facebookresearch/votenet/main/scannet/scannet_detection_dataset.py)、[投票损失](https://raw.githubusercontent.com/facebookresearch/votenet/main/models/loss_helper.py)。

原实现的分组半径、目标框、采样及阈值服务原任务，不直接照搬到地下路口。正式复用前须固定源码commit和许可证；本次网页main分支读取不是依赖冻结。

## 2. SoftGroup也不是无监督地把相近点自动变成正确实例

官方实现预测点语义与偏移，按语义分数选择候选、在偏移坐标上邻域分组，然后用实例特征细化类别、掩码及质量。训练需要点级实例归属、偏移与实例掩码监督。它支持借鉴“分组后判断整体实例”，不能替我们定义路口属于哪些表面。[官方模型实现](https://raw.githubusercontent.com/thangvubk/SoftGroup/main/softgroup/model/softgroup.py)。

## 3. 与本项目的具体差异

| 项目模块 | 实际输出 | 与成熟实例聚合的差异 |
|---|---|---|
| 旧`point_axis_vote` | 每个查询的三个轴线控制点 | 按查询权重对点/偏移加权；不是投票空间局部分组和实例检测，旧失败不能直接算VoteNet失败 |
| 当前候选读出 | 每个固定候选的位置与存在分数 | 没有先聚合成实例；密集候选重复响应问题不能由候选覆盖率证明已解决 |
| `expected_geometry` | 可见锚点、窗口开口及完整性 | 不返回点/面片—结构归属；不能直接供应上述两种方法的训练接口 |
| 分段图后端 | 已知位姿下的短时节点跟踪与穿越状态 | 不负责修复无依据的感知实例；不能让图后处理把感知失败掩盖掉 |

地下结构与物体实例也不同：一个侧壁可能为相邻两个路口提供证据，路口中心可能在自由空间，表面质心不等于结构中心。这是接入时必须检验的任务差异，不是现有论文已经解决我们的任务。

## 4. 本次落地的可检查前提

新增`teacher/gse_instance_support_contract.py`，只检查显式点—锚点正例和已知掩码，不按最近中心生成归属、不把未知改为负例，允许一个点支持多个结构，列出无支持锚点。即使格式通过，`teacher_qualified`和`training_authorized`仍为false。

6个测试通过（0.15秒）：只有中心无法替代归属；未知保留；多支持保留；明确负例与未知分开；矛盾掩码拒绝；同样的点和中心可以对应不同的归属及偏移答案。因此中心坐标本身不能唯一确定投票标签。这是软件反例，不是实测标签人口。

没有生成新教师、标签或训练资产。系统Python没有pytest，实际测试使用已存在的冻结训练解释器完成，未安装依赖。

## 5. 有限接入判断

优先保留“观测证据聚合→结构实例”的机制作为待验证方案，不立刻复刻完整VoteNet或SoftGroup。已有编码器、坐标、面片和评分可复用；需要新增的真正研究接口是可观测结构的支持归属，而不是另起一个地点身份模型。

下一步只读检查现有合成构造与回波来源，确认是否已经保存可支持点/面片—结构关系的证据。先检查字段与来源链，不生成标签；不能仅凭tunnel/node ID或最近中心补归属。尽头封闭表面、交汇分支和近邻双路口分别检查，歧义保留多重/未知。

若来源不能支持该关系，则投票式方案不具备训练前提，停止其接入，不再借更换教师名称绕过限制。若支持，必须先独立验证归属与跨视点结构位置一致性，再登记有限训练。C0对照、额外实例误报、近邻双路口分离和原门槛都保留；本次不授权下一轮长训练。
