## 模型到底会拿到什么

学生输入只有原始LiDAR距离、有效回波标志，以及五帧到当前传感器的相对平移和相对yaw。它们使用原保存精度，不补帧、不按效果换样。相对运动来自既有仿真数据的保存合同，不代表部署定位误差已经验证。

源帧行号和序列身份另外保留作来源核验，不能传给模型。没有导出真实节点、边、基元归属、几何答案、绝对位姿、mesh、模型权重或C08—C10数据。独立穿越中的单个观察也不能拼成连续探索路线；图实验仍需要另行固定的连续或片段轨迹人口。

由于Zarr压缩块比单帧大，实际解码距离字段64926行、有效标志113532行；四个窗口级字段各388392行。精确卡记录各字段的块、有效行区间和padding。这些数字是旁读成本，不是训练样本数；最终只导出原3360观察。全部15960个实际源文件读取与冻结范围一致，导出后再次核对字节哈希。
