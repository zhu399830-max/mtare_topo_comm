# 下一项最小验证：让结构分类读取预测的通道归属

2026-09-05。当前仅完成软件与合成测试；没有执行本设计的真实训练，也没有恢复正式建图资格。

## 要回答什么

原分类器平均汇总所有方向的隐藏特征，没有直接使用成员分支判断的“哪些方向属于这里”。类别贡献对照完成后，预测成员F1由0改善到0.6615，但精度仅0.4963，交汇仍0/14。这说明简单改变类别权重不足以解决任务，不等于已证明新读出一定有效。

下一项只问：固定几何和成员预测后，显式读取成员条件化的几何汇总，能否比同规模、同输入但不读成员概率的网络更好地识别局部结构？不同时重训前端、改变成员监督或增加地图。

## 已实现的软件

`src/mtare_topo/representation/gse_membership_event_readout.py`保留全部候选，在共同机器人坐标系中生成18维输入：原未加权关系均值8维、模型成员概率加权关系均值8维、成员概率之和、数值有效候选数量。小网络为18→32→3，共707参数。默认所有源张量停止梯度，只允许新分类头学习。

对照网络将加权8维和软成员数量置零，保留未加权几何与有效数量，参数布局完全相同。它叫“不使用成员条件”的对照，不叫“无几何”对照。

未知候选保持掩码；前向不读取教师成员、事件、真实节点身份或真值筛选集合，不按0.5筛方向，不写死“3个就是交汇”。软成员数量不是真实通道数，重复预测、错误归属和未知部分都会影响它。数值掩码相同也不能证明扫描身份相同，生产身份绑定仍需单独完成。

20项新合成测试覆盖旋转、顺序置换、全空候选、极端分数、相同普通均值但不同成员分布、源梯度隔离和非法输入；连同旧query与训练器共85项回归通过（2.36秒）。这是软件证据，不是模型准确率。

## 拟冻结的受控小实验

优先使用原未加权00的GT轴与预测轴最终缓存，不从新factorial挑最高F1格子。分别训练成员条件on/off，共四个小头；同初始化、seed0、batch18、Adam0.001、每头300步，拟1200次更新，初始/最终全180观察共1440次小头评估。正式运行前仍须精确输入清单、缓存身份检查、独立training卡、执行器合成验证与预检；本文件不是执行规格或已运行记录。

原C01 S01—S10共180观察、900原帧、1452片段不变。872走廊、14交汇（6独立构造）、0终点；只比较已有类别的容量诊断，不能宣称三分类、完整检测或未见泛化。GT/预测有效候选人口不同，两者差距不是纯几何噪声干预。

独立审查建议严格限定七文件：原export的四输入（`partial_training_inputs.npz`、`manifest.json`、`target_transport.json`、`metrics/summary.json`），原geometry-bound训练的两份GT/预测final预测NPZ，以及同run的`metrics/summary.json`。不读取factorial预测、历史权重或训练过程快照。各文件的精确路径、SHA及行身份仍须冻结，不能只凭数组同形状拼接。

四头统一采用已登记的事件类别平衡权重N/(K*n_class)，仅对已有支持类别计数，旧分母不变；不再增加另一轮权重搜索。GT来源也是GT轴线分支的模型中心/成员预测，不是理想成员答案。与旧00相比同时改变了读出及优化任务，因此只有新on/off之间的差异能隔离成员条件化作用，不能把对旧模型的全部提升归因于这个因素。

冻结源意味着中心对应可在评分/损失侧一次绑定并复核，不能把教师绑定结果用于前向筛选。四头固定final300，沿用argmax，不调阈值或选最好轮数。预先确定事件损失与分母；不能依据训练中表现临时改平衡策略。

主要报告完整混淆矩阵、交汇精度/召回、两类macro-F1、逐父结果和成员条件on/off配对差值。原容量线macro-F1≥0.95只检验拟合能力，完整三类原门保持未通过；必须报告只预测走廊的常数对照。若成员条件无收益，不扩训；若只GT有效，优先分析预测成员/几何误差；若两者都有收益，仍需独立开发样本验证，不能直接升级到闭环。

18维统计不是完整组合表示，不同布局仍可能压缩成相同特征。四头失败不能推断整个几何语义方法不可行；on/off都成功且接近也不能宣称成员条件有独立贡献。若仅GT来源成功，尚需区分成员质量、中心误差、候选人口与读出适配，不能立即归咎于某一项。缺少终点限制三类结论，但不能用来解释已经有标签的走廊/交汇为何拟合失败。
