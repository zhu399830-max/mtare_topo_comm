# 点级表面到轴线读出：已实现，尚未获得训练精度结论

2026-09-05，Phase 3。实现位置：`src/mtare_topo/representation/gse_point_axis_readout.py`。

## 为什么这样改

同180观察的正式诊断已证明：旧900均值点不能表达3153/4356个目标轴点；保留原点后仍有465个目标在表面点凸包外。因此需要同时解决两件事：同一个压缩token内的点仍能被区分；中心轴不再被限制为墙面点的非负平均。

这不是新的论文贡献声明，而是修正前端的一个明确表达瓶颈。论文仍须证明几何组合改善结构节点、端口和探索。

## 实现接口

`FrozenBackbonePointAxisAdapter.forward`只接收原五帧range/valid及因果相对平移、yaw，不接收world/node/tunnel/teacher身份。骨干保持eval、无梯度；复用原`_memory`、slot query与slot decoder。旧关系分数不与新轴线偷偷拼接，因为它们基于旧几何。

新头`PointAxisReadout`有35,460个参数：

1. 保留每个原始回波在当前机器人坐标系中的XYZ。按扫描帧和方位列找到其传感器token；这不是教师基元分组。
2. 压缩token特征经线性投影，与“原XYZ、相对该token均值的XYZ”的小MLP特征结合。因此同一token中的不同高度/深度仍可区分。
3. 点与候选slot计算归属分数，另保留背景通道；三控制点分别学习点级支撑权重，不强制直线、单调或固定顺序。
4. 每个点产生表面到轴线的偏移，包含共享项和低秩slot条件项。偏移头初始化为零，因此初始是原始点读出，而不是随机大幅移动点。
5. 三个控制点对“原点＋该slot的偏移”加权。偏移允许轴线在墙面点凸包外，归属概率参与相对权重。

低秩slot偏移直接输出`[B,S,N,3]`，避免构造`[B,S,N,32]`的大型隐藏特征。第一版仍有`[B,32,3,57600]`的控制权重，不声称已优化到在线实时；训练批量须另测资源，不从batch1外推大batch。

## 为什么不是每个点只给一个偏移

已有源射线可能关联多个构造表面。若强制每点唯一轴线目标，会出现监督冲突。独立审查在生成任何目标前指出了这个问题，因此当前实现允许同一点向不同slot投票；原`[B,N,3]`共享偏移只作为算子支持的消融输入。

这并未解决归属训练本身。将来的监督不能把多源点静默硬分配、删除或当作唯一归属；也不能把教师候选集送入学生forward。当前没有生成点级标签。

## 输出不等于安全证书

输出包括轴线、控制权重、归属概率、归属支撑量、投票离散程度、有效加权点数和方向可分辨标记。

- 即使所有点都更像背景，归一化控制权重仍可能输出一个轴线；因此同时输出绝对归属支撑量，不能用“有坐标”当存在性。
- 权重/点数/离散程度不是已校准不确定性。低离散也可能是错误点群或重复点。
- 方向标记仅判断两端是否超过输入浮点分辨率，退化控制点保留；不是几何准确或可通行判断。
- 点归属仍可能混合不同隧道，软件测试不能保证学会隔离；尚不能直接接图或planner。
- 纯投票算子在坐标与偏移分别按点/向量变换时满足SE(3)一致性；普通坐标MLP和历史骨干不因此获得完整SE(3)等变保证。
- 原始返回缺失或有效输入非有限时失败；无效padding可含NaN，但被清除且不能污染梯度。一个有效点只能给位置假设，不能证明轴方向、宽度或截面。

40项新算子/头/适配器测试，加8项既有均值与raw适配陷阱测试。包括：

- 同token上下层的可区分性；单侧壁之外的轴线表达；偏移梯度非零。
- 同一点对两个slot产生不同偏移；slot/点重排；算子SE(3)；背景概率与存在性区别。
- NaN padding的值和梯度隔离、非法索引/非有限/全空拒绝、退化标记、方差与有效点数解析结果。
- 完整57,600点、32slot、实际历史骨干类的前向/反向；骨干随机初始化而非读取checkpoint，权重逐元素不变、梯度全缺失；新头梯度全部有限。
