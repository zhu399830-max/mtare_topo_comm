# 独立节点—支路联合评分已实现

`evaluation/anchor_branch_scoring.py`先以三维位置作独立一对一匹配，再评价各节点下的方向集合。不读取模型置信度、训练对应或GT身份来优化匹配。调用者必须提前选择预测、冻结距离/角度阈值，并提供独立证据绑定的可评分与可关联掩码。

实际规则：漏掉参考节点，其全部已知支路计FN；错误位置的节点不能因方向相似拿TP；可评分的多余节点及其支路计已知FP；未知位置的多余节点和支路计unresolved。部分参考不输出完整支路F1。参考竞争导致不能关联时，不允许该预测消耗一个已知目标。位置匹配同样最优却对应不同节点时明确拒绝，不用语义选择有利匹配。

9项联合测试0.19秒通过，含空预测、错误位置、未知区域、未知参考竞争、重复节点、几何对应歧义和原方向评分。没有新数据、模型前向或训练。

这补齐了此前“只给匹配路口评分会漏掉整个路口失败”的缺口。纯函数的provenance_verified始终False，它不能代替真实清单、观测掩码及目标读取器认证。单/多机器人图和探索评价未执行。测试使用1米/10度不是正式研究阈值。
