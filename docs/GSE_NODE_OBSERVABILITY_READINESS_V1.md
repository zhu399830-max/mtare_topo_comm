# 节点监督与字段恢复：小实验准备记录

日期：2026-09-05。范围：用户已批准几何组合方案的 Phase 3；不是新教师或训练结果。

## 目前解决了什么

旧物理端点支持不能等同于局部通道口可见性。新增 `teacher/gse_portal_ray_evidence.py` 从有限激光射线检查：射线是否在首次回波之前穿过候选截面的严格内部。允许从通道内向外、从外向内两个方向；没有证据输出 UNKNOWN，不生成负例。

候选截面来自给定的全部可见基元，不按目标节点的真实 incident 身份预筛。原身份只作为教师索引，不能进入模型。候选仍是构造基元端盖截面，不自动等同于语义节点端口，差别必须保留到真实样本检查。

## 独立审查发现并修复的错误

1. 距离 2.2 m 存为 float32 后是 2.200000047683716，直接比较可能把封闭端盖判成开口。现在保留源 dtype，减完整存储 ULP，再减冻结测量/射线算法误差界。适配器不得先转 float64 而丢掉源精度信息。
2. 起点恰好位于截面上时，旋转平移产生约 1e-15 扰动会让原判定翻转。现在近截面起点统一 UNKNOWN，不通过容差后向延长射线；50 个共同刚体变换测试覆盖非中心起点。这会减少支持，不能据此删除样本。
3. 解析场和真实射线 mesh 的采样间距不同，弯折处端盖法向会不同。P1 导出源码使用场间距 0.025 m、mesh 轴向间距 0.05 m、64 个角向分段。候选适配器现在要求显式 mesh 参数，并检查真实多边形截面，不拿更大的理想椭圆代替网格截面。真实 run 仍须绑定源版本。

上述均在合成测试阶段修复，未修改已有数据或标签。

## 证据不能证明什么

- 射线可通过，不证明机器人宽度或安全净空。
- 同一射线穿过多个候选时保守拒绝独占判断。串联截面被拒绝不等于不可见；重合截面不能重复计作两个出口。
- 门面起点仍未知，需要其他几何/多帧证据，不能将数值拒绝变成负标签。
- 所有给定截面都有证据，也不自动证明完整事件类别、终端标签、全部出口数或全局连接。
- 实际射线算法的额外误差界尚未在新教师合同冻结，不能仅靠 ULP 宣布完整真实数据教师通过。

## 冻结骨干读取器

`data/gse_scoped_model_input.py` 只读取精确清单中的窗口/源帧，输出沿用旧骨干的 `range/50`、二值 valid、五帧相对平移与 yaw。归一化、通道顺序及相对位姿计算不改变。

模型输入没有 primitive/node/edge/traversal 身份、教师几何或世界绝对位姿。行号/source index 放在模型输入之外，仅作复现索引。测试确认修改无关身份数组不会改变输入。禁止任务在读取前拒绝，不初始化所有分片。

本轮仍仅合成验证，未用元数据库存卡解码真实扫描。原库存卡权限不扩大。

本轮验证：新增两模块 40 项测试、扩展回归 147 项全部通过，完整回归 1.31 s。冻结 Torch 2.9.0+cu129 在主机模式实际执行 CUDA 标量成功，未加载模型或数据。软件结果不作科学性能指标。
