# 有限偏移截面适配与原99条件只读检查

新增`aperture_polygon_boundary.py`，从原两端点、恒截面扫掠基元的64边形mesh构造有限半空间。检查侧条带平面一致性；弯管、变截面输入拒绝，不拆段替换。球面三角单元使用覆盖范围对每个半空间给出整单元上下界，无法确定的边界带保留unknown，不用单个中心点代表整单元。

20项回归通过（0.79秒）：三截面偏移重叠、平行/分层、有限尽头、变形输入拒绝、内部采样与整单元界一致，及既有开口接口/径向球冠测试。

## 下一步：观测证据，而非拿几何库存充当可见标签

为75个受支持条件接入原五帧射线的稀疏边界穿越见证：只有有效射线在首次返回前穿过当前窗口边界，才可记录该位置的观测支持。关联到unknown单元或多个可能分量时保留歧义；单条射线不能把整块边界单元标为已观测free，更不能证明完整背景或可通行。复用现有因果位姿和射线接口，不引入GT ID筛选候选。
