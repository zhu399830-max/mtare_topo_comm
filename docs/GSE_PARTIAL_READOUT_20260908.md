# 部分监督输出不再使用未训练头控制建图

训练代码明确冻结anchor_uncertainty、dimension_evidence、opening_support、validity_anchor、validity_opening五个模块，但旧推理读出仍使用其数值筛开口、关系和锚点。这不是可靠的不确定性估计，可能在学习结果有用时错误拒绝结构。

默认读出现在为 `partial_geometry_v1`：

- 锚点位置及存在概率、开口位置/方向/存在概率、归属概率仍从模型输出读取。
- 未监督的尺度、尺寸可信度和支持/有效性头不参与决策。尺寸和锚点不确定性保持None。
- 当前没有物理可通行标签资格，读出返回unknown。DTO的(0,0,1)是显式弃权，不是声称网络校准概率；原网络全部logit与概率仍存raw evidence。
- 数值支持仅表示实际观测输入存在，不表示每个查询可见或归属可靠。图端原存在概率、归属阈值、多帧稳定、歧义和真实穿越要求不变。

旧全头读出仅作为显式 `synthetic_all_heads_v1` 合成诊断路径保留；原合成测试明确选择它，不把随机/理想输出冒充训练模型。

由于旧图端强制要求已知uncertainty，直接输出None会使全部节点消失。现在部分读出接图时必须显式选择 `known_pose_partial_diagnostic` 配置，否则报错，不静默生成空图。该模式不使用未校准尺度门，但保持原稳定次数、存在概率、空间关联与歧义拒绝；配置写入图snapshot。不改变局部规划器或物理安全合同，也不宣称部署定位和可靠回环已完成。
