# 第一个非空目标生成分支：部分锚点参考位置

新增`gse_reference_anchor_targets_v1.py`，输入原bundle和原交点，通过既有源/帧/量化XYZ校验后重建进入证据。局部构造路口至少有三个不同向内方向的进入证据时，产生current_sensor坐标的参考锚点位置目标；不直接接受junction_supported布尔断言。

位置来自程序构造参考，不是由这些射线精确估计出的可观察点，也不声称完整几何逆问题唯一。返回显式标记PARTIAL_REFERENCE_POSITION_ONLY。构造身份与见证射线只在独立teacher_provenance中，损失记录无node/edge身份。仅两个方向或无证据保持未知；隐藏的第四方向不抹掉已支持的三向事件。

这不是完整标签生产器：开口与归属仍无目标，完整背景标记仍False，full_training_gate_eligible=False。不能将该分支称作完成原三任务拟合门，不能以此启动正式A/B/C或宣称完整语义标签已认证。

3项新增生产逻辑合成测试加10项源轴向/方向解释回归，共13通过（0.81秒）。新增测试隔离替换观测解释输出以检验生产逻辑；实际观测解释已有独立真实30核验，本次没有重新读取/标注真实样本。测试确实生成非空位置目标并经observed_targets转为有效损失张量，同时验证未知不转负例、teacher身份不入损失。

下一项补齐独立开口/归属及可评分区域的目标生成和反例，不恢复更多数量诊断。真实目标导出需独立精确卡/spec及合成合同完成；现有6036输入、旧模型、论文图片不变。项目目标仍是完整独立建图收益，不以部分位置监督替代。
