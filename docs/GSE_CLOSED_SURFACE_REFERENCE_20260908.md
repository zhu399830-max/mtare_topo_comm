# 来源审计的闭表面参考已接线

新增`closed_prism_surface.py`，复用独立声明的有限棱柱平面，不读取生产triangle ID或报告来源来选择候选。旧距离算法不修改。

与旧开放内部区间不同：

- 进入与退出参数相等的切触保留为[t,t]。
- 沿表面行进的共面射线保留有效区间，而非丢成空交集。
- 平行且在体外的射线仍为空交集。
- 共面区间只有与该float32返回距离的存储格相交时，才为该返回保留额外表面可能性；不会因远处存在共面表面就把所有返回都标未知。
- 进入面、退出面分别输出；无经验几何容差。

15项联合测试0.13秒通过，包含切触与旧参考差异、共面/体外、正常内部、平面顺序、方向尺度、声明参考接线、共面观察格内/外以及上轮存储格反例。

边界：这是双精度数值参考，不是经过误差界证明的精确几何认证。`surface_uniqueness_certified`保持false，不能由一个候选直接升级训练资格。下一正式人口审计先报告兼容性与歧义规模；若需要证明排除其他来源，要独立处理数值边界，不悄悄将当前计算当证书。
