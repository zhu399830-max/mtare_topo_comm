# 通用原mesh适配：24弯曲条件已接通，未知边界仍保留

新增`aperture_mesh_boundary.py`。不修改或拆直原mesh：检查闭合、定向一致的三角面邻接，用AABB排除明显外部单元；其余单元查询到原表面的距离。只有单元覆盖球远离全部表面时，才在中心计算原double/packed32网格绕数，二者近整数且一致才给内外状态。内部重叠允许绕数大于1，接近内部面同样保守保留unknown。

重要边界：Open3D距离为float32数值查询，使用显式数值保护量，但不是严格验证过的距离区间。因此结果声明为工程几何proxy，不是安全证明或合格训练标签。每次分类2亿三角形×点运算上限，超过就失败，不截断数据。绕数查询失败保留unknown，不将失败冒充blocked。
