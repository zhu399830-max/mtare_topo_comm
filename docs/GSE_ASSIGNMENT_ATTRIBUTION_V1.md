# 同一最终缓存的结构候选双匹配归因

2026-09-05，Phase 3。上一轮是真实推进：三组900步GPU实验及多实例候选层已完成。本轮不训练，唯一问题是位置与结构属性是否落在不同候选上。

## 固定输入和比较

仅原C01十父地图、180观察、900既有帧、1452可见基元。读取已封存目标导出的四文件，及已封存三分支最终预测、900步训练历史和训练汇总，共九个payload。三分支各180个已缓存预测，共540个缓存观察；0新扫描、0模型前向、0checkpoint、0optimizer。旧结果、阈值和数据不改。

每支保留1206个中心、886已知事件（872走廊/14交汇/0终点）、2152正成员/13489负成员，方向对应丢失的3正/21负仍为UNKNOWN。GT/预测有效候选数2892/11520差异不隐藏。全部180是原拟合数据，不称泛化。

1. 原样复现最终纯中心几何匹配的aggregate、逐父指标、评分mask和query对应；不使用训练matches替代它。
2. 使用同一最终预测快照和原最后一轮十个18观察批次，调用原`region_set_losses`重算联合匹配。保留原五项权重、50米中心尺度和批次分母，不改变损失。历史训练matches只属历史，不当成最终快照的对应。
3. 逐目标比较是否同query、中心距离、事件预测及成员TP/FP/FN/TN。全部14次交汇列完整对照，不能挑案例。
4. 对两种对应中的正/负已知成员报告概率均值、中位数、10/90百分位及固定0.5判断。不搜索阈值或选checkpoint。

联合匹配依赖事件/成员答案，它的分数只能用于失败归因，不能换掉独立成绩或宣称部署检测成功。原联合例程在等代价时选代表解，本诊断不宣称其唯一性。纯中心匹配原有未知/歧义处理保留。所有缺失和原始分母随指标保存。

## 如何改变下一步

如果同一最终缓存中语义正确的候选主要不是位置最近的候选，优先研究中心和属性绑定；如果两种对应都差，再检验类别不平衡和表示能力。不因为任一答案条件化分数高而恢复三种子或闭环，不因为本轮分数低就否定几何组合原理。
