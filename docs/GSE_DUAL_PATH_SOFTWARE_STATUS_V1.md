## 人工复核工具怎么使用

打开 [离线复核页面](../tools/v3/review/gse_structure_review.html)，载入由后续受控exporter生成的匿名盲看包。现在没有正式包，不需要用户开始标注。

盲看包仅含不透明片段键、当前传感器米制坐标和21个决策位置；每个位置绑定五帧因果来源与点云。逐步提交当前判断后才能前进；21项全部提交后才允许加载独立构造参考。未知字段使用null，完整/未知区域框不得重叠。工具不会替用户把表面点击点认定为交汇中心，也不自动填尺寸。

下载记录经`import_browser_review`绑定两个原始文件字节SHA，再重放所有盲看提交/揭示顺序。复核人身份为自述，不是密码学认证；浏览器流程不能防恶意篡改，也不能证明源点云确实只来自声明五帧，后者须由exporter/reader核实。参考后的说明与盲看记录分开，不覆盖原判断。
