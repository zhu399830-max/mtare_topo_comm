## 3. 候选与共同模型

R0：原始XYZ＋冻结五帧上下文，直接结构查询。
R1：现有.5米体素/PCA/18维面片属性。
R2：SPG独立CPU几何分块；只用XYZ→geof→cut-pursuit，不装完整旧Torch/SPT，不运行Delaunay建图。默认k_geof45/k_adj10/reg.1/voxel.03/edge_weight1，保留verticality加权；记录原随机性和两个依赖commit。

R1/R2分别比较B（自身属性）、C0（邻居消息但关系置零）、C（邻居＋真实9维几何/射线关系）。共享128维、三层、8邻居、32锚点/64开口查询。报告有效参数与全链成本；C-B不是唯一几何关系隔离，主机制还看C-C0。

首轮不加入跨变体loss，不换全骨干，不复活707/旧端点身份训练。SPT/EZ-SP/PTv3仅在明确分块/前端瓶颈后作为独立后置候选，不为失败不断增加网络。

## 4. 自动监督与接口验收

生产器与独立检查器分离；检查器不调用V8最终标签判断来认证V8。从原扫描首次返回、完整表面入口、参考连续性、来源/遮挡/歧义检查证据。Unknown不转负，不同ID不直接否定，同观测不同隐藏地图不能产生矛盾确定答案。自动参考不叫人工金标准或物理安全证明。

先原10观察，再12类×3截面×4位置=144合成五帧；之后才依据冻结清单扩到既有人口。合成类型：直道/尽头/T/Y/四岔/双路口/平行/分层/坡道连接/可见阻挡/隐藏支路/重合歧义。有效数量由实测记录，不假定全合格。

标签字段单独资格化：归属缺负例则停归属结论，但有效锚点/开口可做条件诊断；完整背景缺失不报完整F1。若锚点也不可评分，工程备案为固定metric anchor＋学习开口，撤回学习建节点主张，不包装成功。

训练、推理共享 RepresentationPacket 构建函数；原始坐标/运动/面片/射线关系必须一致。原teacher CPU grid与学生观测grid职责分离，教师绝不进入模型前向。
未训练uncertainty/support/validity头不得作可靠门；缺监督字段输出unknown。已训练概率可校准并报告熵，不称物理风险概率。

统一独立评分：锚点4米主合同附1/2米；开口1米、方向连续误差；几何一对一匹配，额外预测与未知分别统计；C07校准后冻结，不用开发反复选阈值。

## 5. 实验与选择

32拟合观察最多500更新：锚点/开口F1≥.90、锚点位置≤1米，仅有合格完整区域才能给完整F1。一次定位修正仍失败则不扩训。

筛选最多8模型：R0，R1-B/C0/C，R2-B/C0/C，R3；seed0各500更新。仅calibration选择，开发暂不打开。先排无效/泄漏/超限，再按锚点与开口父图宏F1排序，差≤1pp选全链延迟更低者，最多两表示进入决定性比较，R0必保留。

决定性比较各2000更新；AdamW .001/wd .0001/microbatch1/accum4，同顺序、初始化、输出、目标、后端。不挑中间最好checkpoint。有独立收益才追加1/2种子。

完整扩大线：节点、开口、边相对对应基线各≥5pp，逐父图置信区间、未知/拒绝覆盖与错误分类完整报告；3种子至少2满足且平均增益成立。小人口仅初步依据。
