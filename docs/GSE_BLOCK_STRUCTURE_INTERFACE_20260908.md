# 块内点云已接至锚点和开口输出：软件完成，尚未训练

## 当前计算链

同一份原始点按体素面片或超点分组 → 每块逐点形状编码128维，同时汇总旧冻结观测特征128维 → 拼接真实中心、观测范围与退化标志 → 共同结构读出。

读出使用128维、两层、四头解码器，32个独立锚点查询和64个独立开口查询。没有教师提供的候选位置，没有把块中心当作答案，也没有生成全局连接。开口仍沿用已有10米窗口球面合同，不是新定义的物理通道端点；锚点单独预测在局部范围内。

实现：`gse_block_structure_readout.py`、`gse_block_structure_loss.py`。它们是新的共同输入/输出软件接口，不是重新启动旧候选模型，也不是训练成功证据。

## 输出与未知

输出锚点位置和存在logit、开口位置/方向和存在logit，以及输入是否有观测。结构事件类型、宽高、根可达性、开口成员归属及校准不确定性明确列为未知，没有生成看似完整的猜测数值。现有45原型参考仅用于支持其已定义字段，不能因此宣称完整结构语义模型完成。

## 损失接口

只用三维位置做一对一匹配，不用预测类别或置信度挑选有利对应。位置按已有10米单位归一化，方向采用单位向量夹角相关项；未检出权重0.1显式固定在软件中。正式实验前这些配置仍需统一冻结，不允许运行中选择损失。

完整可评分区域：匹配预测为正，其余预测计负；不完整区域：仅监督已知目标，其余未知。方向未知可保留NaN，只有有效方向进入计算。没有目标又没有完整性证据时，损失返回独立可微零，不给模型制造负标签。目标超过32/64容量、重复位置多义性、无观测却给正标签均失败。

这不是沿用旧候选拟合成绩：新接口的结构预测质量尚未测得。共享参数仍可能被其他已知任务更新，不能把“未知任务无损失项”理解为所有未知输出数值永久不变。

18项联合软件测试通过，0.83秒。覆盖分块置换、输出范围、已知目标反向到点编码器、冻结特征无梯度、完整空目标对全部查询计负、未知方向NaN不污染损失、完全未知无模型梯度、空观测与容量失败。
