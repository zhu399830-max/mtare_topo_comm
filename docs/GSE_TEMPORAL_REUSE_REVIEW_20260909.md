# 跨帧确认：已有代码与真正缺口

本次仅查看代码、原训练卡与307观察源索引，没有读取新扫描、测试世界、模型权重或生成新轨迹。

## 可复用但尚不能宣称部署成功

`gse_surface_graph_v1.py`具有多锚点三维坐标变换、短时一对一邻近匹配、歧义保持候选、连续稳定计数和分段状态。配置明确标为软件未校准；它接收SurfaceObservationV1，包含独立开口，与当前AnchorBranchObservationV1的“每路口若干方向”不是同一个接口。不能补假开口位置、假不确定性或假事件标签来强接。

`gse_segmented_graph_v1.py`可以隔离片段，避免跨段补边；其旧内核以事件及机器人位姿为输入，不是多个独立路口位置。因此不把机器人位置冒充预测路口，不能直接替换新的多锚点接口。

短时位置稳定只是必要的时序证据，不是路口真实性证明：稳定误报也可能被计数确认。既有软件未完成当前学习输出的配准、开口对应和真实连续图资格，不能把调用成功当成该证据。

## 当前307观察不支持连续图比较

冻结卡中307观察属于156个任务容器：70个只有1例，49个有2例，18个有3例，14个有4例，1个有5例，4个有6例。同任务按当前帧排序得到151个相邻记录对，其中当前帧相差1的为0，仅3对五帧窗口有重叠。这些是元数据计数，不是物理连续性证明；不能按真实边身份重新排序拼图。

`continuous_trajectory.py`的欧拉行程生成直接读取graph及splines，是仿真路线生成组件，不是从扫描恢复连续性的工具，也不是已有连续LiDAR证据。

## 下一步固定范围

先从已授权C01–C07旧数据的现有序列清单/数组元数据检查是否存在同一物理穿越内连续的扫描—位姿记录，记录五帧历史是否越过穿越边界。不读取C08–C10，不生成新世界或扫描，不调用教师候选。先核实可用人口、间距、位姿来源与分区，再为任何新增推理绑定独立数据卡。

若只能找到单条穿越内连续观察，研究结论只限局部跨帧结构跟踪，不能称回环或全局探索。若没有有效连续记录，明确报告缺口，不用307样本或教师欧拉路线伪装完成。感知C0/C1未达到增益条件的结论仍然保留，时序机制不能替它“补成绩”。
