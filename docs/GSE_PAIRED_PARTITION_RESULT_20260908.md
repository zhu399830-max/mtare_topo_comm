# 同输入几何表示对照：45例提取完成

## 做了什么

在同一批已经封存的45个合成观察上，完整运行了两条几何表示路线。输入仍是五帧激光和相对运动；没有新训练，没有生成新教师答案，没有读取真实测试地图。

- **固定体素面片（R1）**：把空间按0.5米格子划分，每块计算中心、法向、粗糙度和观测支持。
- **经典几何超点（R2）**：使用已固定版本的SPG几何特征与cut-pursuit分块；保留官方原始结果，同时提供按已有邻接连通部分拆分的映射。它是几何表示，不是可通行图，也不是结构检测器。

两者共用当前传感器坐标、10米范围和同一份float32原始点。所有属性由原始回波统一计算，不用体素中心等权代替原始点。范围边界不是通道尽头，分块边界也不是出口。

## 可以看什么

[打开全部45例XY/XZ分块对照](../results/gate3_semantics/gate3_20260908_gse_spg_paired_extraction_v1_seed0/previews/partitions.html)

每例展开后可看两种表示。颜色只表示所属分块，不是模型已经认识了路口。预览每视图最多显示1500点，完整点、原始射线索引、五帧支持和两种分块映射均保存于该运行的`artifacts/partitions/`，没有为了图好看删除评分样本。

这45例包含直道、尽头、可见阻挡、T形、Y形和四岔，以及三类截面；并非45个独立真实地图。当前批次不包含上下分层和近邻双路口，不能把软件反例成绩当作这些场景的实测结果。

**目前能说：两种表示已能在同样输入上完整提取并比较。不能说：超点更少，所以结构识别更好，或者建图创新已经成立。** 本轮没有预测锚点、开口或拓扑边，旧检测器失败结论未被改写。

## 实现中解决的问题

旧坐标函数和非学习优化器处于同一模块，导入会要求独立环境没有的`liblbfgsb.so.0`。本次只接出坐标计算，并测试与旧函数在共同float32边界后逐元素一致，不为无关算法安装依赖、不修改旧模型。34项联合软件测试通过。

运行前固定数据卡、规格、源码及1,994个Python/包/运行库文件；预检零错误、零警告。只有一个正式运行，未覆盖或重试。原生调用前后环境核验一致，训练环境未修改。

## 下一步与停止边界

下一步只读这45例已封存输出，比较分块空间范围、表面近似残差和退化情况，定位大分块是否混入需要分开的几何细节，并对照保存的图。它是信息保留诊断，不设一个新指标来宣布路线获胜。

完成这一步再决定共同结构读出怎么接；不立即重训已耗尽纠错预算的候选头，不增加种子，不把R2几何邻接直接当作机器人通行边。Phase3研究问题仍未通过，不进入拓扑探索实验。
