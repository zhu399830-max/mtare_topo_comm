## 核验内容

- 固定分块seal及数据卡、45个NPZ逐一校验SHA；旧紧凑缓存校验固定整体SHA。
- 缓存观察ID、五帧顺序、输入绑定哈希与分块运行的源清单一致；全部编码器状态相同。
- 原始射线索引在缓存中有效、帧索引一致；900个传感器特征的布局符合原合同。
- 两条路线均使用块中全部回波加权汇总，点数与封存分块记录一致。

旧缓存容器包含历史目标张量，反序列化会载入容器；新加载器只访问`header`和`compact`学生字段，不构造或传递历史目标对象。不能把它表述为容器没有标签。
