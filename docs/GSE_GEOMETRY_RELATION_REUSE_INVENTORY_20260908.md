# 从几何到结构：已有接口、可复用部分与缺口

本次只读源码和运行14项纯软件测试（0.84秒），没有读取C01—C10数据载荷，没有新标签、模型推理或训练。文件存在不等于完整数据已验证，更不等于模型成绩。

## 不是从零开始，也不是已经完成

最新BlockStructureReadout使用几何块内形状、位置和冻结观测，通过集合注意力输出位置/开口。它可能隐式利用关系，但本轮R0/R1/R2只改变分组，没有关系移除对照，不能归因于组合关系。

此前说“中间没有明确监督”只适用于最近这组位置拟合任务，不能泛化为整个仓库从未实现关系学习。以下都是已有实际代码，而非新命名。

| 已有部分 | 实际字段或机制 | 能复用什么 | 不允许推导的结论 |
|---|---|---|---|
| 通道几何监督 | `PrimitiveRelationNumpyBatch`的三点轴线、两端截面半轴、超椭圆指数 | 几何训练目标、掩码、传感器坐标接口 | 构造切分端点不是天然开口，轴线不是回波表面 |
| 构造组合 | `EndpointComposition.member_endpoints`、`anchor_xyz_m` | 离线连接真值与组合身份 | 学生不能读取node/primitive身份或由真值筛选候选 |
| 五帧对应 | `temporal_correspondence`及dustbin | 可见构造基元在历史与当前的监督对应 | 构造基元重现不是全局地点回环，不能直接用于地点合并 |
| 原端点关系 | `endpoint_attachment`来自同一构造节点成员 | 物理参考层、历史失败分析 | 任意部位有回波就监督隐藏连接不符合局部可观察结构任务 |
| 端点可观察性 | `endpoint_support_gaps`与`endpoint_observed` sidecar | 区分已支持端点与隐藏端点、保留未知 | 裁剪轴线接近构造端点只是既有代理，不能冒充自由路径或安全证明 |
| 断开但角度重叠 | `disconnected_angular_overlap`来自不同连接身份且共同方位列支持 | 分层/遮挡歧义监督候选 | 它不是可见障碍，也不等于可通行性负例 |
| 面片关系模块 | 9维相对位置/距离/法向关系/有效性/射线证据，3层局部消息 | 现成关系输入与局部邻居实现 | B到C同时改变邻居消息和关系属性，不能独立证明属性收益 |
| 显式Composer | 出口方向、宽度、竖直轮廓、置信度及跨帧transport；另有几何变化时序 | 结构事件与几何接口分离、因果历史处理 | 老出口方向为二维bearing，不等于完整三维结构；接口要求有效字段不等于已获得可靠预测 |

## 关键源码位置

- `src/mtare_topo/data/primitive_relation_batches.py`：几何/传感器/关系同批容器；训练入口必须继续分离目标和学生输入。
- `src/mtare_topo/data/primitive_relation_targets.py`：端点关系和跨帧身份来自构造/射线来源；聚合可见基元后为成员端点填连接，没有在该原始函数内检查连接处可观察性。
- `src/mtare_topo/evaluation/primitive_attachment_observability.py`：原始监督缺少端点观测条件的说明、裁剪支撑与端点间隙。
- `src/mtare_topo/data/primitive_relation_observable_batches.py`：检查sidecar来源对齐和`unknown_never_negative`约定。
- `src/mtare_topo/representation/gse_surface_relation_model_v1.py`：已有显式关系张量及B/C消息路径，不能声称仓库没有关系机制。
- `src/mtare_topo/representation/gse_typed_composers.py`、`teacher/gse_composer_supervision.py`：既有出口集合/几何变化组合与五帧监督，不自动覆盖新三维开口归属任务。

## 为什么现成标签不能直接接到彩色分块

监督ID描述的是生成时的通道基元，体素/超点ID描述的是观察点分组。两者粒度不同：一个分块可以混有多个表面来源，一个通道可以分成许多块。因此不能把分块编号换成构造编号，也不能把每个块按最近真实路口赋归属。当前45例拟合目标只有27个锚点和84个开口，没有被该训练合同确认的块—结构归属监督。

## 固定下一步，避免第三轮直接坐标试错

1. 不复活失败坐标头，不追加seed或loss搜索。
2. 在已有代码上写纯软件关系合同反例：相同单块属性但不同相对布局、上下分层、基元/块编号置换、缺失连接观测。明确输入几何关系与可观察结构目标的区别；邻居不代表可通行。
3. 使用现有关系模块设计同邻居/同消息计算的关系属性移除对照，避免原B/C同时改两件事。此步只验证机制，不宣布科学收益，不生成新教师。
4. 软件合同成立后才绑定具体既有数据清单，核对关系目标实际人口；标签缺失保留未知，不强制补齐。拟合通过、开发收益及建图收益仍须分别证明。

关系损失不是学习关系的唯一方式，也不是方法创新本身。最终仍需用共同输入和图后端的对照证明：几何关系减少漏路口、假分支及错误关联。以上盘点只明确复用条件，不把14个软件测试包装成论文成果。
