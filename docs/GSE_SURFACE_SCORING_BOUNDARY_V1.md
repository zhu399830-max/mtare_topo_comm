# 新结构输出的评分边界

旧`gse_spatial_event_set_metrics.py`固定16真值目标，匹配使用按target逐个枚举已用prediction位集的递归。它保留为旧实验代码，不适合作为最多32锚点/64开口的新通用评分器。本次未用新代码重写旧成绩。

新增`evaluation/gse_surface_detection_metrics_v1.py`：调用者传入冻结置信度阈值、几何匹配距离及已确认完整的评分球域。支持最多64查询/64目标，匈牙利分配先最大化距离内有效匹配数量，再最小化几何误差。类别、预测置信度不进入几何匹配代价；置信度只用于固定阈值筛选。匹配距离没有在本模块调参。

所有已知目标必须计入漏检，完整区域内多余/重复预测必须计入误检；区域不完整或域外预测单列未知，不能当负例，也不能删掉它们后宣称全场景高F1。没有完整区域或存在域外目标/预测时，full_f1返回null。空目标/空预测不自动得到1分。该接口不能证明调用者提供的完整性为真，也不给Gate成功。

7项合成测试通过（0.15秒）：额外预测、重复预测、未知不伪装完整F1、最大匹配非贪心、64查询规模和置换、三维域外、容量超限拒绝。没有实际模型或真实标签评分，没有训练。

下一项仍为局部观测标签生产：路口分支几何证据、开口及可信评分区域。不能因为评分接口实现，就将现有来源计数/端面部分证据自动标为完整标签。旧实验代码与成绩全部保留。
