# 条件位置负监督接线与独立方向集合评分

本轮只做软件，不读新研究样本、无训练。旧损失和旧评分不改。

## 已实现

`conditional_anchor_branch_loss.py`将已有bound_reference_exclusion接入新方向集合头：正记录/source/hash及显式参考下标绑定同一冻结清单；目标位置须与选定参考完全一致。只给未匹配且有原观测排除证据的位置增加presence负项，共用原presence归一化分母。匹配正例优先，其他构造参考含尽头仍留在排除全集内，不把它们当缺失节点。完整区域合同不能和条件负例混用。支路方向来源仍须由既有认证读取器保证，本包装器不冒充它已验证所有方向标签。

`branch_direction_scoring.py`用独立几何匹配评价单个已对应路口的方向集合，先最大化容差内匹配数，再最小化角误差；不复用训练对应或置信度。完整参考可计重复/错误预测FP，部分参考只记unresolved，不报完整F1；漏掉已见支路记FN。该函数不能评价漏路口、错路口或完整图，节点对应与未知区域覆盖仍由外层独立评分负责。

13项组合测试通过，包括正目标优先、未知梯度、错来源/内容拒绝、反向不能当同向、重复不能多计TP和空预测漏检。测试角度10度不是研究阈值，不写入正式规格。
