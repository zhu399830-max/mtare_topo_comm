# 固定12观察的来源核验定义

当前只完成判定软件与定义，没有运行研究数据人口审计、改变来源或生成标签。

## 分开三个问题

1. **退出来源**：射线在并集第一返回处，哪些通道由内部变为外部；这是当前渲染记录报告的集合。
2. **可能表面来源**：考虑存储距离精度，返回位置附近是否还有其他通道的进入面、退出面、切触或共面表面。它不一定与退出来源相等。
3. **唯一来源资格**：只有前两项兼容、其他来源被可靠排除，才可供现有teacher中要求单一来源的见证使用。codebook只有一个ID不够。

## 固定数值边界

将存储float32距离与上下相邻可表示数的中点作为闭区间。使用闭区间保守保留round-to-even边界，不加1厘米、1e-5米或其他经验合并容差。1e-5米仍只属于已完成的距离对照线，不移用为来源合并半径。

软件分别标记区间内可能进入面与退出面；切触[t,t]不能作为空交集丢弃。共面或几何计算不确定由调用者显式传入，不允许缺省忽略。现有`ray_intervals`只保留正长度内部区间，并排除平行边界，不能直接拿其空值证明“无其他表面”。

新增`source_rounding_diagnostic.py`通过7测试（0.08秒）：2米处非对称存储间隔、不同退出面落入同一存储格、进入/退出区分、切触/共面不确定、舍入边界与非法输入拒绝。一个可能来源仅称singleton_candidate，不自动获得surface_uniqueness_certified。

## 后续人口保持不变

固定原12声明、60帧、691200条，以及两份已封存来源：完整距离诊断与五帧转换。613785条单一报告来源和77415条多来源均纳入，不只选单一来源或成功样本。无C01—C10/模型输出/checkpoint读取。

下一实现独立有限棱柱的**闭表面区间**与显式退化标记，覆盖切触和共面，复用已声明截面，不调用生产求交记录来筛候选。先软件验证该几何参考；然后在独立精确audit卡/spec中统一运行上述固定人口。浮点参考候选不能直接当精确几何证书，遇到无法排除的其他表面保留未知，不静默改码或升级teacher资格。

本项只决定现有teacher来源见证可否使用，不解决完整背景标签，也不等于结构学习或建图成功。
