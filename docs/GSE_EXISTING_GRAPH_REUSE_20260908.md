# 现有建图资产：能复用什么，不能冒充什么

本次只读源码并执行68项已有软件测试（0.26秒全部通过），无训练、无数据导出、无真实图回放。

| 组件 | 实际能力 | 当前缺口 / 使用边界 |
|---|---|---|
| `semantics/nonlearning_geometry_observation.py` | 五帧范围图估计宽高等；当前帧长距离扇区检测出口；按出口数等规则输出事件 | 无运动对齐输入；出口是平面heading，最多6token；不是独立三维锚点或分层开口检测器 |
| `topology/gse_graph.py` | 按行程间隔生成metric anchor，或稳定事件生成结构点 | 节点使用传入机器人位置，不是预测路口中心；固定间隔不是学习结构贡献。部分外部backend使用association_key，必须核查其生产来源 |
| `topology/gse_rule_graph.py` | 距离、事件、出口方向的节点关联消融 | 无配准验证，不能替代严格重访合并。局部node_id是图内ID，不自动等于真值泄漏 |
| `topology/gse_surface_graph_v1.py` | 独立三维锚点短时跟踪；分段、采样到达、实际轨迹边；中间节点不静默跳过 | snapshot明确跨访问合并=false、持久开口匹配=false、部署源绑定=false；只属已知位姿诊断 |
| `topology/gse_registration.py` 与binding | Open3D点到面配准证据；点云/部署位姿输入、图内候选ID | 不执行候选检索或合并决策，不能因有ICP模块就说回环完成 |
| `topology/gse_surface_prediction_binding_v1.py` | 拥有模型前向的观测接线、帧字节绑定、三维变换 | 文档明确上游编码器/真实reader来源未认证；预测可达性不是执行安全证书 |

## 避免两种错误比较

1. 旧非学习方向基线没有三维中心。不能给它补真实路口中心后与学生比节点F1，也不能把机器人位置假装成路口中心。
2. 独立穿越不能按真值边号拼为连续轨迹；当前45独立合成观察只能做感知诊断，不能生成有意义的全局连接成绩。

## 已验证软件范围

68测试来自 `test_nonlearning_geometry_observation.py`、`test_gse_surface_graph_v1.py`、`test_gse_segmented_graph_v1.py`、`test_gse_causal_graph.py`。覆盖直道事件、理想三维锚点、分层、前缀一致、跨段不补边、外部执行回执以及稀疏轨迹不跳中间节点。它们不是非学习方法在真实地图上的性能证明。

## 最短的有效下一步

先在已经封存的同45合成扫描上只读运行旧范围图基线的默认规则，记录事件、开口方向和数量，按原型分组。只与共同可评分的出口/事件字段比较；不为它编造三维位置，不修改默认阈值。用该结果回答“现成几何方法能否避免恒定报一个节点的错误”，再决定结构事件门控或固定metric anchor哪个值得作为独立备用系统。

若采用固定anchor＋学习开口，论文必须改称“学习开口/局部结构改进图上的探索信息”，而不能继续宣称学习产生结构节点。此处尚未选择该替代路线，也不把它当原计划成功。当前学习主张未证实，继续停止本模型配置扩训。
