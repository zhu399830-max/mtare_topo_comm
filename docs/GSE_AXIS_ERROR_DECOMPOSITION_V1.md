## 当前解码器的一个具体限制

实际observable模型继承sparse-port实现，其几何路径为：

`16条竖直线×4方位列的坐标均值 → 每帧180点/五帧900点 → 三个独立softmax加权控制点`。

相关代码是`primitive_relation_model.py::_token_xyz`与`primitive_relation_sparse_port_model.py::forward`。特征编码器可以保留部分高度信息，但控制点的位置仍被限制在这些均值点的凸包中。

新测试`test_gse_coordinate_pooling_limit.py`直接调用现有池化函数：上下两层z=±3m经平均变为z=0；所有加权轴点必然z=0，目标高度的平方误差恒为9，对注意力logits梯度恒为0。原始未合并点仍保留±3m。同样构造可发生在不同深度。该反例证明**这个读出存在不可表达的坐标情形**，不是本轮真实180观察全部错误的因果证明，也不是实际扫描渲染实验。

另一个待验证风险是三控制点各自对全点池独立混合，没有显式点归属或顺序约束；不能只凭代码断言它就是此次失败根因，也不能立即堆loss。

## 唯一下一步与修正边界

先为同180观察冻结**原始坐标池可表达性**的精确卡/spec：只取既有900帧range/valid和因果相对位姿，不运行模型/加载checkpoint，不生成标签。比较旧900均值坐标池与未合并返回点池对同一教师控制点的几何可表达性/误差下界；退化点云、凸包与数值容差必须明确，不把上限当学生成绩。现有metadata-only卡禁止扫描解码，必须独立授权数据范围。

- 若原始点能表示而均值池不能，最小候选是保留原始XYZ旁路并薄改几何读出，复用encoder/temporal/slot骨干及权重。
- 若均值池本身能表示，不能把失败归咎于池化；再测固定小样本的点归属/控制注意力与几何梯度，不直接启动完整训练。
- 点归属引导几何估计是可借鉴的成熟范式：SPFN先预测点属性，再进行可微参数估计，而非直接回归所有基元参数；其任务是机械模型基元拟合，不能据此宣称地下扫掠通道已验证。[SPFN论文](https://arxiv.org/abs/1811.08988)。这属于前端工程借鉴，论文创新仍须由几何组合改善节点/端口及探索的独立消融证明。
