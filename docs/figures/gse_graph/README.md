# GSE-Graph paper figure contract

## 2026-08-31 active-method override

The active paper method is now the construction-supervised primitive-relation
structural graph in
`docs/PRIMITIVE_RELATION_STRUCTURAL_GRAPH_PLAN_V1.md`. Existing `gse_*` bundles
remain immutable baseline, ablation, and failure-analysis evidence. In
particular, `gse_method_overview` describes the superseded event/exit-token
method and **must not** be used as the main-method figure.

The active paper requires the following new evidence-bound bundles:

- `primitive_relation_method_overview`: procedural construction supervisor,
  five causal scans, swept primitive set, attachment/overlap/temporal relations,
  persistent graph, traversal-only edge commitment, and unchanged M-TARE local
  execution stack. This is a schematic and contains no outcome values.
- `primitive_relation_dataset_overview`: paired ellipse/rounded/C1-mixed worlds,
  identity-preserving ray provenance, five-frame cropping, and exact split/count
  sources from sealed P0/P1 evidence.
- `primitive_relation_nonlearning_baseline`: already sealed in the C07 baseline
  run; publication bundle must copy its PNG/PDF/SVG and machine-readable metrics
  without manual values.
- `primitive_relation_training_and_c07`: three-seed curves, selected checkpoint,
  same-input geometry/relations, uncertainty, and nonlearning comparison; cannot
  be published until the active training/evaluation run is complete and sealed.
- `primitive_relation_causal_graph`: fixed outcome-blind worlds showing
  predicted primitives/relations, persistent nodes/ports, verified edges,
  provisional rejects, and objective TNG overlay.
- `primitive_relation_single_robot` and `primitive_relation_multi_robot`:
  paired coverage-time, travel/redundancy, failure, and communication evidence.
- `primitive_relation_ablations_and_failures`: required single-variable
  ablations plus selected old scientific failures that explain the method
  transition.

Every new bundle must keep PNG, PDF/SVG, source JSON/CSV/NPZ, deterministic
publisher, source-run IDs, outcome-independent selection rule, and SHA-256
manifest. No existing paper figure is deleted before its baseline/ablation or
supplementary role is finalized.

Every paper or supplementary figure stored here must include:

- publication raster (`.png`);
- vector source/output (`.svg` or `.pdf`) where applicable;
- deterministic generation script;
- machine-readable source values (`.json`, `.jsonl`, `.csv` or `.npz`);
- non-outcome-based sample selection rule;
- source run IDs and SHA-256 manifest.

Do not delete a source result until every file above has been regenerated from its sealed evidence and independently hash checked. Temporary previews and exploratory plots must be kept outside the final figure index.
