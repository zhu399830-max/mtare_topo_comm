# 五帧输入到公共特征的来源绑定

2026-09-07。本轮是 Phase 3 软件准备，真实地图读取、特征导出、标签生成、训练更新均为0。

新增 `src/mtare_topo/data/gse_surface_feature_input_v1.py`：接收已冻结清单指定的六字段 NPZ 字节、文件 SHA、task、行号、序列编号和五个源帧编号。先核对同一份字节的 SHA，再解压；限制六字段及解压大小，禁止教师额外字段、错帧、错序列、非法 mask、非有限值和错误当前帧运动。C08—C10 task 不允许。

输入形状沿用现有每task16观察合同。只按旧编码器的50米尺度归一化距离，不做10米裁剪，保留全部有效回波。身份信息留在独立 provenance；网络数值输入只有距离/有效性及因果相对运动。文件本身不包含task字符串，因此必须由调用方用冻结清单绑定task到文件哈希；本模块不会认证任意调用方声明。

12项新增测试通过，连同13项编码器加载测试共25项通过（1.56秒）。测试包括相同数值但不同源帧产生不同来源摘要、20米回波未被裁掉及错误源行拒绝。不是实际3360观察已经提取；真实导出仍需精确源/权重/环境规格冻结和预检。
