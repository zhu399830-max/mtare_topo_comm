# 按原射线求交输入重放端面

实现 `gse_caster_cap_replay_v1.py`：按原caster先float64归一化方向，再将网格顶点和射线起点/方向转float32；不再次归一化量化方向。调用Open3D list_intersections，比较返回的float32交点参数与原保存值，要求精确相等，不新增距离容差。

实际Open3D 0.19.0合成核查确认：理论1米的简单交点返回0.9999999403953552米，而非1.0。最初测试错误地假设后端等于解析1米，断言失败；已纠正为独立后端调用产生基准，未修改真实数据或放宽匹配。对相同后端结果精确对应通过，返回2米的反例无见证。

专用Open3D环境没有pytest，因此实际后端核查采用直接断言脚本；主Torch环境pytest为1通过、1因无Open3D跳过。不能声称两环境完整pytest均通过。

## 限制和下一步

单个完整基元mesh重放并未重建原全场CSG距离分组，原距离可能来自同组另一表面；此时只能不确认，不能把容差扩大至分组宽度。还要绑定原输入方向来源、几何身份、因果帧和保存的来源集合。当前尚未用于真实S08案例，不能声称已经修复那两例。

下一步在原精确案例范围冻结数值重放诊断，先比较原float32顶点/射线和后端命中，再决定真实对应结果。旧全人口结果不改写；新标签0、训练0。远端才返回的米级差异不是本修正的目标。
