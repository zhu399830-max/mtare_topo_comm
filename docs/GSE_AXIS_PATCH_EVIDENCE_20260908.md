# 轴线与观测面片交会证据

新增 `representation/gse_axis_patch_evidence.py`。仅输入有效拟合轴线及已有SurfacePatches，不读取地图、身份或标签。输出三维交会位置、是否唯一、是否落在实际回波外接框、法向与轴方向关系和超出拟合轴段的距离。平行、退化和无效法向保留未知掩码及NaN位置，不能填成机器人原点。

这不是尽头分类器：外接框包含交点只是必要的局部代理，不能证明交点存在实心表面，更不能证明全通道封闭。所有输出的whole_tunnel_closure_verified均为False。原始面片的范围、粗糙度及支持量继续由调用方保留，不改标签或默认面片参数。

33项联合测试通过（0.48秒，含7项新测试）。端面测试正确定位x=3而不是拟合轴线裁剪端点x=2；平行侧壁没有交点；偏离轴线的局部端面虽存在平面交点但不满足范围代理；带孔四点和小障碍即使通过范围代理也不声明封闭；空观测、退化和反向轴线均有明确行为。

本轮0新扫描/标签/模型推理/训练。与旧全轴对候选组合后的召回尚未测量，不能声称18个尽头已恢复。

下一步冻结同45封存扫描的端面候选诊断：共享默认轴线、固定0.5m/10m面片提取，保留有效交会点的支持与外推记录，独立统计实际候选数量和1/2/4m匹配。判为候选不判封闭，所有六类计入。若局部面片代理仍不能覆盖可见终止位置，停止基于该候选的完整节点筛选训练，不用真实端点补候选。已有交汇候选成绩与旧模型结果保持不变。
