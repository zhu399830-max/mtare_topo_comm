# 局部开口参考目标生产器

本次完成软件接线，不新增真实数据读取、标签导出或训练。

`gse_reference_opening_targets_v1.py`调用已有源绑定窗口诊断，要求有限、排除竞争的穿越射线及表面返回同时存在，生成当前机器人坐标中的开口参考位置与方向。参考来自原构造的10米窗口截面，不能称为点云唯一恢复的真实开口中心。身份、弧长、射线索引单独留在教师证据，不进入损失记录或模型候选。

窗口开口不生成持久节点。未知宽高为None；没有锚点时归属矩阵只有空行，不猜测同一隧道就属于同一路口。缺穿越或表面支持保持未知；重复位置和超过64容量报错，不折叠或截断。完整区域标记仍为False，不把未标目标当负例。

验证：新增5项生产器测试，加已有锚点、目标适配及窗口诊断/提议回归共29项通过（0.99秒）。生产器测试模拟诊断结果，只证明转换、掩码及失败处理接线，不能证明真实标签质量。真实导出0，训练更新0，正式训练资格仍否。
