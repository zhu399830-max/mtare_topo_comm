# 结构定位失败：球面饱和与逐例证据

## 可展示结果

[六类同场景预测图集](figures/gse_block_fit_diagnosis_20260908/index.html)包含直道、尽头、可见阻挡、T/Y/四叉路口；固定圆形截面和中央视点，不挑最佳例。绿色圆点是结构真值，红叉是模型结构位置，蓝方块和橙加号分别是真实及预测窗口开口。已查看T形图确认中文和标记可读，全部9个派生文件哈希核验通过。原run不变。

## 逐例检查

45个观察的32个结构查询，每组1440个。忽略置信度后，R0仍有21/27个真值在1米内没有任何候选；R1/R2均为27/27。不存在“已经定位正确但置信度不足”的漏失。R0和R2各12/12个普通直道观察被误报结构节点；R1该项为0。该诊断不改变原评分。

## 坐标接口缺陷

实际`BlockStructureReadout.forward`使用 `xyz = 10 * raw / max(norm(raw), 1)`。raw超过单位球后，输出被固定到10米球面，丢失径向自由度。

| 分组 | 初始化球面查询 | 最终球面查询 |
|---|---:|---:|
| R0 | 1440/1440 | 1323/1440 |
| R1 | 1440/1440 | 1440/1440 |
| R2 | 1440/1440 | 1440/1440 |

球面统计使用`abs(norm(xyz)-10)<1e-4 m`仅用于数值诊断，不是评分或训练阈值。所有值直接来自封存初始/最终预测；研究人口未新增。

对真实位置为原点的样例，球面上的位置损失恒为1（距离除10），其对原始坐标的梯度为0。因此单靠该位置损失不能把该输出拉回窗口内部。通过实际模型、零坐标头权重和偏置控制的两个纯软件反例确认：raw=(2,0,0)输出(10,0,0)，梯度全0；raw=(0.2,0,0)输出(2,0,0)，径向梯度为1。`test_gse_block_anchor_radial_diagnosis.py`两测试通过0.60秒，无优化器更新。

## 结论边界与下一步

这是共同模型输出/优化接口缺陷，不是数据或显卡问题。本轮分数保持原样，但不能据此否定几何表示能力或选定胜出路线。其直接解释中心目标的零位置梯度；共享网络的其他损失仍可能间接改变raw（R0部分输出已进入球内），不能声称任何参数都绝不移动，也不能把全部误报归因于它。

继续盲目训练、调置信度或更换分块不能作为修复依据。下一仅实现版本化候选坐标参数化的软件对照：保持三维球域与未知边界，检查中心/近边界目标的径向梯度、尺度、旋转一致性及数值稳定性；旧模型/权重不改写。通过前不登记新训练，修复也不预先宣称方法成功。沿用用户常规自主授权，不需要更改数据范围或验收标准。
