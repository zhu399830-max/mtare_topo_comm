# 固定3360观察：结构覆盖读取范围

目的：先核对原定观察附近有没有结构候选，避免像30观察端面诊断那样在没有候选的人口上讨论检测效果。本阶段是空间覆盖，不是可见性，更不是训练标签。

固定人口不变：70父地图，1120独立边级单位，三变体3360观察；拟合2880、校准240、开发240。只需要每个观察当前帧XYZ，不读取五帧激光、yaw、回波来源、模型或C08–C10。

`gse_surface_coverage_scope_v1.py` 已从封存选择清单和源哈希索引精确定位：210构造文件、210个位姿数组头、264个位姿块，共684条计划输入路径。构造与位姿块尚未读取。由于压缩块不可分，3360个选中当前位姿需解码656520行（含相邻未选行），填充后总量19927728字节；统计只使用选中3360行。

本轮实际仅读取213项元数据（选择seal、选择清单、源seal和210数组头），没有导出资产、生成标签或训练。六项纯软件测试通过，校验16个当前决策行、原float64精度和压缩块连带读取计数。

下一步冻结此范围的数据卡与单次覆盖统计运行。统计使用既定open10m锚点距离，分别记录degree-one末端、degree-two构造分段、degree>=3路口；degree-two不算学习语义节点。按父地图去重实体，三变体不当三份独立证据。结果不得据此声称结构可见，也不据此重新挑样本。
