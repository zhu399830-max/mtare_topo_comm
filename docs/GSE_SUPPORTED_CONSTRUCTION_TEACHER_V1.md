# 构造真值＋局部观测支持：原180观察的结构监督定义

2026-09-05，Phase 3。用户已授权主线实施与合理方案选择。本文固定一次小规模标签pilot，不开放完整训练、C07–C10或图实验。

## 修正此前额外前置

几何结构学习需要可靠的构造答案和明确的观测支持掩码，不需要先从有限扫描数学证明完整自由空间。[SPFN](https://arxiv.org/pdf/1811.08988v1)使用CAD基元和点归属监督；[Semantic-Relational SLAM](https://arxiv.org/html/2310.00401v2)使用场景关系真值学习几何关系。这支持采用构造监督，但不证明我们的五帧任务已可学，也不允许把全部隐藏拓扑直接作为可观测目标。

取消此前草稿对所有标签要求先构造独立region外壳/完整开口证明的额外条件。保留“不向学生提供GT身份/候选”“隐藏支路未知”“不把构造连接冒充实际穿越边”。不改变原事件/端口精度验收门。

## 一次pilot的固定范围

原C01 S01–S10、c1_mixed，密封的180观察、900唯一原始帧、1452可见片段。父地图是独立单位，原100个采样节点只作历史人口信息，不选择本次标签。每个观察使用其全部可见构造实例。

需新独立卡精确绑定既有teacher字段、900帧range/valid/source membership/teacher-only位姿、10份构造和码本及源哈希；未冻结该卡前不读取新增数组。0模型、0优化器、0扫描重渲染、0新地图。输出全部180行有效/未知与原因，不因支持率重新选样。

## 标签操作定义

1. 按原生成器0.025米原生轴采样，复用每帧来源回波的最小/最大轴索引及数量。五帧并集的最小/最大索引形成已存在的裁剪支持区间。量化距离并不新增空间半径。
2. 对构造成员，将其composition anchor投影到对应realized operand的同一原生采样轴。位于支持区间内才有局部成员支持；两端独立保留，同tunnel不折叠。锚点与真实cap分开。
3. 有至少一个无明确冲突的局部支持成员，才为该构造实例提供中心回归目标。anchor只进入目标与集合loss，不喂forward、不预筛预测候选。
4. 成员正例仅限支持的构造成员。负例仅限已在另一个被支持实例中确定归属的方向锚点；其他方向UNKNOWN，不能把“不是本节点”全部改成负例。这里是构造成员监督，不是独立开口或物理连通证明。
5. 所有incident成员均获局部支持且无明确冲突，才按degree使用corridor（2）或junction（>=3）目标。缺支路时事件UNKNOWN而已支持成员可训练。degree-2只是局部走廊类别，不作为语义节点强制建图。
6. terminal（degree1）还需要first-return落于真实源终端cap的正表面证据。仅无穿越射线、构造degree或区间到端，不足以标终点；未实现/未证实时保持UNKNOWN，不杜撰类别人口。
7. 原生索引投影存在数值等距歧义时保留UNKNOWN；多来源回波若含明确非incident来源关系，保留冲突标记，不用于确认受影响关系。无该证据不证明全世界体积隔离。

这是**工程观测支持代理**：区间可跨越没有实际采样的间隙，来源成员也不代表射线看到完整交汇区域。必须保留原始支持数、区间、投影索引、有效字段和未知原因。构造中心回归是预测目标，不宣称输入唯一决定该坐标。不能拿代理标签上的高分当物理安全证明。

## 决策规则与成本边界

先合成验证：T路口遮挡第三支时不标corridor；多实例不依赖旧target_node；支持区间缺口局限可追溯；相似分层方向不靠GT筛forward；数值投影歧义不猜；终点缺cap证据未知。然后仅一次原180/900 CPU pilot复核现有teacher一致性并报告全部新标签人口。

有支持的中心/成员目标可以进行相同query头的GT/预测容量对照，但必须单列具体字段和人口。若terminal或任一必需类别不足，原三分类macro-F1门不能宣称通过；不把partial task换成完整主方法成功。原180没有真实跨形状配对人口，一致性消融仍需后续独立清单。若明确发现构造与物理几何冲突，停止受影响目标并报告，不改mesh或teacher来掩盖。
