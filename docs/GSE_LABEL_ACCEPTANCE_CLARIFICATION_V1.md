# 回到实际标签质量，不要求证明逆问题唯一

2026-09-07。依据已批准的 `GSE_SURFACE_RELATION_EXECUTION_V1.md` 第“教师与标签”“三个有限先行检查”及备案部分核对。没有新数据读取、标签导出、网络更新或阈值修改。

## 纠正执行中的额外要求

原方案要求本五帧支持相应分支或终止、隐藏区域保持未知、构造身份不进入模型、标签来源和可评分覆盖明确。它**没有要求逐样本证明残缺扫描对应的完整几何逆问题全局唯一**。后续诊断不应把这个更强条件新增为所有监督学习的门槛。

已有反例仍有效，但结论有限：两个有效射线加局部表面支持不足以保证参考中心已观测；局部截面低残差不是位置正确性的证书。它们不说明所有构造参考中心错误，不说明真实60候选全部不可监督，也不构成几何学习失败。

这不是自动批准现有候选。正式使用标签仍须绑定可观察结构、位置定义与证据，对已发现的具体歧义保持未知；完整背景不能凭“没有候选”推断。程序生成的答案与独立评价的答案来源必须公开，不能把教师自洽统计当检测精度。人工未发生仍明确称自动诊断。

## 开发人口的实际限制

已封存空间统计表明，固定开发240观察里只有5个附近尽头、5个附近路口。两种节点按degree定义互斥；它们的观察帧可能重叠，所以不能把帧次数相加。该空间参考清单最多提供10个候选实体，不是10个合格标签。

端面V2现有支持只有4个独立开发尽头；分支来源诊断覆盖5个独立开发路口，但“来源出现”还不是局部连接证据。两类已有记录合起来至多涉及9个独立结构实体，**不是9个有效锚点，也不是物理上只有9个可见结构的证明**。未获支持的第五个尽头需保留未知；不通过放宽端面匹配或添加相邻帧凑数。

原方案开发锚点最低10独立实体/3父的要求尚未证明满足。原30观察候选pilot又只有一个独立路口，不能代替全开发集质量核查。可通行/不可通行标签还受机器人合同缺口约束，继续采用已登记的停止物理标签备案。

## 下一动作及边界

标签工作聚焦现有候选实体的可观察结构与位置对应、明确未知及可评分区域；不再追加位置灵敏度、局部拟合或“唯一性证书”。源构造参考可作为训练答案来源，但不能仅凭候选存在直接填写整个目标包。
