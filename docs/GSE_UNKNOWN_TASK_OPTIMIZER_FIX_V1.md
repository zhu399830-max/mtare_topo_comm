# 未知任务的优化隔离修正

## 完整训练接线验证补充

新增部分观测标签→observed_targets→实际A/B/C模型→micro1×4累积→AdamW的合成集成测试：两个合成观察，每组一次更新。开口存在头发生更新；全未知的方向、尺寸、可达及归属专属头参数逐元素不变。不仅检查输出叶张量，也检查实际模型state_dict。测试通过，未读取真实数据或生产标签，不能称作正式A/B/C成绩。首次检查方向/尺寸/可达通过后补齐归属头断言，再次通过。

2026-09-07，纯合成软件检查；不读取真实观测或权重，不构成新训练实验。

发现：原损失将所有潜在监督输出乘零以保持空批可反传。宽高标签全未知时，尺寸梯度仍为零张量而非None，AdamW会施加weight decay，已有动量时也可能继续更新。使用既定lr=0.001、weight_decay=0.0001合成复现，尺寸任务有效计数0，数值3的输出仍改变约3×10⁻⁷。

修正：空损失使用独立可微零，不连接模型；空索引的损失项直接跳过。实际有效任务的公式、权重和分母不变。整批无监督仍由runner跳过optimizer。

验证：损失、训练器、标签适配合计45项原有回归通过（21.44秒）；追加冷启动及已有AdamW动量的隔离测试后，损失与适配35项通过（1.16秒）。两种情况下全未知尺寸输出及其优化器状态逐元素不变。旧测试仅要求零梯度，已改为要求None，不再把零梯度当成无更新。

边界：只保证整个任务无有效监督时不建立该任务的反传路径；共享特征仍会因其他有效任务而改变。部分宽度有标签、部分高度未知时，共享头和正则化也可能影响未知预测；不能宣称未知预测数值永远不变。此修正不是校准或语义教师验证。
