# 旧几何方法在同45观察上的实际表现

`inspect_fixture_nonlearning_baseline.py`已只读执行退出0。扫描SHA逐一绑定原45合成观察；默认参数未调整，0训练、0新标签。输入为相同五帧距离图/掩码；它不使用相对运动，主要出口判定来自当前帧。未补真实三维位置，未把平面方向成绩当三维检测分数。

| 场景 | 观察数 | 默认输出 |
|---|---:|---|
| 直道 | 12 | 全部走廊，2方向；没有路口/尽头事件误报 |
| T中央 | 3 | 全部交汇事件，0/180/270度三个方向 |
| Y中央 | 3 | 全部交汇事件，0/120/240度三个方向 |
| 四叉中央 | 3 | 全部交汇事件，0/90/180/270度四个方向 |
| 尽头 | 12 | 6走廊/2方向，6尽头/1方向 |
| 可见阻挡 | 12 | 与尽头组相同 |

尽头/阻挡各三截面的view0和view1仍输出前后两个方向，view2和view3只保留后方。原限定oracle在view1已经有可观察终止参考，故各3个view1存在反应延迟；view0不能仅凭构造类型强制判尽头。前方误方向约349.5度。这里没有重新定义全世界事件真值或给出泛化F1。

## 对研究选择的影响

新模型在直道恒定误报结构点，而旧规则能分清这些简单事件；新模型Y/四叉仍漏支路，而旧方向基线在中央无遮挡条件已正确。不能以模型loss下降或相对初始化进步作为几何组合成功，也不能省略这个强于预期的现成对照。

但旧方法没有独立路口中心、分层方向和配准关联；把出口数量变化位置当节点仍会出错。因此它不是已完成的GSE-Graph替代品。保留为方向/事件基线，不注入GT中心，不声称完整系统成功。

## 下一步限定为方法接口决策，不再扩训旧头

证据支持把“观测到的候选结构”与“任意32个空间查询”分开评估。下一检查现有局部点云/几何候选能否提供可追溯、无GT的三维候选及跨帧位置约束，形成一份候选提议→学习筛选/几何修正→图更新的可行性合同，与现有自由查询方法保留对照。

这是待验证备用接口，不自动替换主线或宣称创新成立。必须先回答：候选召回是否足够、候选是否来自当前/过去观测、普通走廊是否没有假结构、分层/遮挡是否保留未知。缺少三维位置证据时停止该候选，不用机器人位置或teacher identity补齐。已有几何关系模型的局部开口输出可保留为消融，旧训练不重启。
