# 五帧稀疏观测支持已接入75个原合成条件

`aperture_sparse_support.py`复用CausalRaySegments。只接受因果有效射线；计算从历史传感器位置穿出当前10米球域的正交点，要求交点严格早于原首次返回，减去源float32一个ULP及显式误差界。恰在返回处、无效返回、球面起点和未来帧不计支持。

球面交点对应的所有可能相邻单元必须已知free且属于同一几何分量，否则保留未分配；不按最近中心猜归属。支持是射线位置上的稀疏见证，不把整个单元提升为observed，不提供完整背景/实例标签。

21项回归通过0.77秒。只读工具`inspect_synthetic_aperture_geometry.py --with-support`核验封存哈希和原绝对/相对运动及来源编码，对75个有限恒截面直管条件完成检查（375帧出现、4320000射线位置）。其余24弯管/坡道仍unsupported。退出0，无重渲染、无新标签、无训练。

|---|---|

| 平行，12例 | 全部2/2，未把完整几何另一通道的开口变成已观测 |
| 分层，12例 | 全部2/2，上层两几何区域支持数均0 |
| 重叠，12例 | 3例2/0，8例3/2，1例3/1 |

圆形重叠中央例的3个几何分量分别有670/832/690条支持射线；4491条球面交点落在unknown边界等不能唯一赋属的位置，未强制分配。旧两个参考截面属于同一负Y区域，并遗漏另外两个有观测支持的物理区域。不能由支持射线多直接宣布完整标签或学习模型成功。

当前额外量测误差界明确为0，仅对已保存合成渲染按源dtype ULP作诊断，不是实体激光噪声认证。原标签、分辨率及评分条件均未改。

## 下一步

将确定受支持分量、未确定边界碎片、参考截面多对一关系形成统一诊断读出；存在unknown连通可能的片段不得直接计为多个实例。先冻结其语义和回归，不新增教师版本或完整F1。
