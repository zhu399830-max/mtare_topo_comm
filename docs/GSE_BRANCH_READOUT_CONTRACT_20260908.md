# 支路证据与现有模型：复用边界和下一实现合同

## 软件实施结果

`block_anchor_branch.py`已将旧块特征adapter和全部96个decoder查询复制到独立模型，保留原自注意力上下文，首32查询接新支路头。旧输出头不复制，旧模型没有被修改。32项联合测试通过1.33秒，包含查询逐元素一致、旧参数隔离、梯度到块特征但不入冻结context、空观察返回None。复制的是调用者提供的模型组件；本次测试使用合成初始化，不代表历史checkpoint已加载、数据已绑定或训练已执行。后续先做数据/背景准入，不继续叠加网络。

新增`anchor_branch_readout.py`接受Q×128观测查询，复用平滑路口坐标映射，独立学习每路口的支路方向集合。12项读出/损失联合测试通过1.05秒，包含合成梯度、查询置换和退化方向拒绝。测试K=4不是正式配置；当前只有查询头与损失接通，尚未接实际编码器人口。该头没有入口尺寸、位置、物理可达性或身份输入，不意味着完整方法完成。

`representation/anchor_branch_loss.py`已实现独立部分目标和损失，复用现有`_assign`位置/方向几何匹配与歧义拒绝；不使用来源身份或置信度匹配。5项测试通过1.00秒。预测Q×K支路方向保留在各自路口内，完整性按路口提供；入口坐标和尺寸不参与损失。全未知时has_supervision=false且与模型参数断开，运行器仍必须跳过优化器。接口只设有界容量（Q≤32、K≤64），尚未冻结实际读出的K或训练规格，不能将软件上限冒充已决定的模型结构。本轮没有研究训练。

## 已核实的阻碍

1. `gse_block_structure_readout.py`的开口位置经过`window_surface_positions`，强制落在半径10米球面。V2只改变anchor坐标映射，开口限制仍在。
2. `gse_block_structure_loss.py`对开口预测和真值都检查10米半径，先按位置匹配，再监督方向。它不能接只有方向、没有入口位置的支路证据。
3. `gse_surface_losses_v1.py`虽有独立属性掩码，但方向已知要求`opening_valid`，后者仍需几何定位参与匹配。把未知入口填成路口位置会改变任务且制造重复位置，不能这样适配。
4. 旧稀疏基元损失使用完整matched集合的存在与数量监督；旧稠密极坐标损失对未激活格子算负例。不能直接用于缺完整背景的部分支路参考。

## 可以直接复用的机制

已有观测编码器、块/面片特征、集合注意力，以及不将未知当负例的损失设计。运行既有`test_gse_surface_losses_v1.py`中unknown/negative/complete相关测试：8通过、16未选，1.00秒；不是训练或完整模型测试。

仓库不是没有负例代码。`gse_surface_partial_losses_v1/v2`存在条件参考排除和重复预测监督；但开口排除来自所有轴线与10米球的交点，明确只适用于窗口开口。新支路任务不能继承这项完整性假设。

## 输出含义必须分开

| 输出 | 位置 | 方向 | 当前身份 |
|---|---|---|---|
| WindowOpening | 10米窗口截面中心 | 截面外向 | 保留的旧任务/对照 |
| AnchorBranchReference | 所属参考路口位置，不是入口位置 | 从路口指向支路的参考轴向 | 已保存证据的读取视图，非模型预测 |
| LocalEntrance | 真实局部入口位置 | 三维入口方向 | 完整方法待实现目标，不能靠改名获得 |

## 下一步固定为软件接口，不开始训练

在旧读出之外新增独立的“路口查询—支路方向集合”接口，复用128维查询特征，不把方向挂在必须先定位的窗口开口上。先实现部分目标/损失合同及纯软件反例，不新增研究数据或teacher。

- 路口位置、支路方向分别匹配；匹配不使用真实ID或置信度挑有利对应。
- 同一来源连接不同路口的两端独立存在；跨路口方向相同也不能合并。
- 没有正例不自动表示没有支路；未知方向和不完整背景不能产生负梯度。
- 完整性必须显式提供，不能从已保存三条支路推断恰好只有三条。
- 入口位置、宽高、物理可达性保持未知，不填假值。
- 全未知样本不推进优化器；拟合通过不等于检测或建图通过。

这个接口是用于定位“结构关联能否学”的中间诊断，不是缩减最终论文目标。决定是否训练之前，必须明确独立样本、负例/背景、容量及公平对照；原12组只含两个真实路口，不能作为泛化证据。最终仍须证明几何关系对节点、局部入口和图的独立收益。
