# 候选训练失败定位：来源捷径与目标响应

只读核验两个封存run的seal和目标文件哈希，再读取全部45观察的最终预测；0模型推理/训练。原结果不改。

## 实际选了什么

B和C逐索引均为45/45观察只选择轴对候选，不只是总数碰巧相同。

| 分组 | 数量 | B分数中位数 | C分数中位数 | 达到0.5的数量（B/C） |
|---|---:|---:|---:|---:|
| 全部轴对 | 34 | 0.9781 | 0.9798 | 34 / 34 |
| 面片正支持 | 438 | 0.2120 | 0.3609 | 0 / 0 |
| 面片背景 | 31997 | 0.0030 | 0.00066 | 0 / 0 |

轴对中30个目标>0，4个目标为0。前者并非30个独立节点，是9个节点附近的重复提议。面片正支持目标的逐观察均值为0.3255–0.3683；C分数有响应但没有学出高于阈值的中心峰，背景也存在最高约0.4248的局部误响应。不是完全没有梯度或所有输出都一样。

## 损失为什么允许这条捷径

按封存2000样本暴露顺序精确累加原BCE权重：轴对正支持总权重200，轴对背景总权重仅0.081573。原因是4个错误轴对分别混入上千个背景，单候选惩罚被平均得非常小。

对“所有轴对输出同一个分数”这一受限模型，BCE解析最优概率是加权目标均值，计算为0.9747126，与B/C轴对约0.978的输出相符。这个解析结果不需要新训练，说明当前目标确实允许一条代价很低的来源捷径；它不是证明真实网络内部仅使用来源信息的因果干预实验。

因此失败不应概括为几何学习不可行，也不能靠降低0.5阈值掩盖。原损失在实现上按规格运行，但没有充分惩罚最危险的错误结构候选，同时把尽头监督作为稀疏局部软响应。

## 接下来只修有证据的问题

继续停止本配置扩训。先在软件层比较损失权重合同：必须让少量错误轴对获得明确代价，且不能把重复候选数当独立结构样本；将“只有来源类型的常数预测”作为损失设计的退化对照。对于尽头必须明确中心峰检测与区域支持分数的区别，不能将平均响应高就当定位成功。
