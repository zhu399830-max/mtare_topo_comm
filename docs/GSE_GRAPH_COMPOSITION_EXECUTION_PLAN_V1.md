# GSE-Graph：几何基元组合驱动结构建图（实施版 V1）

状态：USER_APPROVED，2026-09-05。授权来源：用户完整提交本方案并明确要求实施。
目标是代码、冻结模型、严格未见结果、单机与 2/3/4 机器人对照、必要消融、可复现证据、论文及投稿 PDF 全部交付；组件通过不等于论文方法成功或保证录用。

## 研究问题与贡献边界

学习三维通道基元的局部组合，能否比出口识别和同后端非学习几何更可靠地产生节点、维护端口与实际穿越连接，进而减少重复探索？

仅验证两项贡献：几何变化下保持局部结构关系的组合学习；结构观测驱动、未知关联不阻断执行连通性的在线图更新。SPFN 的基元拟合、Cano 的出口导航、PRISM-TopoMap 的检索加配准、MR-TopoMap 的图增量共享均作为已知方法，不重复宣称创新。

参考：<https://arxiv.org/abs/1811.08988>；<https://onlinelibrary.wiley.com/doi/10.1002/rob.70157>；<https://arxiv.org/abs/2404.01674>；<https://nicsefc.ee.tsinghua.edu.cn/nics_file/pdf/8ac5aaef-72e5-4d5b-ad39-5adb4cad8d91.pdf>。

## 已有证据的正确边界

- 180 观察/500 步短训练失败不证明理论不可观或方法不可能；浮点余弦距离为零不证明两个原始输入相同。
- 教师节点描述使用构造身份挑选 incident 基元，只是理想组合上限，不能冒充学生部署结果。
- 几何相对旧非学习基线有改善，但尚未证明其绝对局部误差满足建图需求。
- 旧 13 条 trace relation 只恢复 2 条，其中 8 条端点未提交、3 条 proposal 缺失；这一小人口不等于全地图边数。状态机影响需 oracle 干预验证，不能直接断言唯一因果。

## 数据和训练

复用 80 父世界、240 几何实现、757290 帧、564378 五帧序列。C01--C06：426552 序列训练；C07：64644 序列开发/校准。变体按父地图整体隔离。C08/C09 有历史开发暴露，不重新命名为严格未见。C10 先审计访问记录、不读资产；污染则另冻新父世界规则与种子。

教师来自构造关系、spline/截面和五帧射线支持。未知结构不当负例；已有 endpoint observability 复用，不包装成新贡献。配对几何一致性仅约束共同可见的结构，不强制真实变化的宽高一致。

编码器/基元权重复用。新组合头显式输入共同机器人坐标的相对位置、夹角、高差、截面与置信度，输出 corridor/junction/terminal、端口归属和不确定性。回归/事件/端口/配对一致性分别掩码。地点身份不是该头的训练目标。

180 观察只作为已知小实验人口：新输入所需的共同坐标与端口监督必须先核对，不能从旧 44 维缓存捏造。训练前冻结精确 Data Card、标签/可见性、采样和 run spec；沿用用户持续授权而非伪造新批准。

## 在线接口与实现顺序

StructuralObservation：时间戳、事件、局部端口/基元及不确定性；PoseEstimate：部署位姿与协方差；GraphUpdate：新节点、确认/拒绝关联和理由；TraversalEvidence：离开端口、连续实际轨迹、到达节点与执行状态。

第一步只实现纯合成软件验证（0 地图、0 数据集帧、0 训练），不开放正式地图回放或 M-TARE。新节点由稳定事件确认，不等二次到访；离开到达之间依次建边，保留所有中间节点。回环候选必须有配准、端口和轨迹一致性证据；多个有效候选拒绝合并并保留新节点。

不读取 GT node/edge/traversal 身份作为运行输入；online trace ID 由运行时生成。每次更新只读当前/过去输入；历史快照不可因未来更新变动。未走端口仅为探索目标；边需实际执行证据。必要定位锚点与结构节点分开统计。

## 快速验证和停止线

1. 旋转/置换不变量；角度、高差和分层变化敏感；空支持、精确对称拒绝。
2. 合成 oracle 状态机完整恢复可观察节点/已完成连接，前缀一致，无假边。
3. 固定短轨迹上真实/预测几何与事件交叉替换，后端不变；理想输入失败先修系统。
4. 180 观察 tiny：训练事件 macro-F1 >=0.95、端口 F1 >=0.90，仅代表接口容量；不再要求总 loss 降 95%。
5. 独立父世界单 seed 短训与无基元消融；无初步组合增益即停止扩大。
6. 完整开发后才三 seeds 0/1/2；事件 +5pp、局部几何 MAE -10%、合并 P>=.99/R>=.60、node/edge F1 分别 +5pp；平均增益且至少 2 seeds 满足主指标。按父世界统计 CI，拒绝全部拒绝的虚假安全。

新研究指标不回写旧 run。系统错误可以修软件并重跑单元测试；正式科学失败只停止受影响阶段，必须先保留证据和归因，不增加预算/降低门槛掩盖失败。
