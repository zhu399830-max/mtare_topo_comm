# 复用原接口交点，区分进入与离开

新增纯数值解释器`teacher/gse_directed_interface_evidence_v1.py`，不重新拟合截面、不读取实际数据。输入是原网格接口交点、原float32首次返回、射线方向、实际源轴向和回波来源。

同一位置的相反接口不要求严格先后顺序：射线沿该分支实际向内轴向穿过接口，且首次返回在接口之后、来源唯一对应，才记录进入证据；反向单独记离开。多来源、遮挡、切向、同一节点无法区分的多个同向源接口仍未知；重复三角形不重复计射线。实际源轴向不能取辅助connector方向。

此解释不宣称所有来源接口都是可见结构开口，不产生稳定锚点或完整背景，不证明地面可达。它取代的是对证据必须有严格交点顺序的依赖，而不是降低标签门。原ordered-crossing诊断及历史结果保留，不改写。

4项合成测试0.14秒通过：共面相反arc可区分、同向同源歧义、多来源/遮挡未知、重复三角形/记录顺序不改变结果。尚未接入真实bundle或执行真实诊断，没有新标签或训练。

下一项将已有`gse_junction_interface_diagnostic_v1`的原始交点与真实源轴方向/量化射线绑定此解释器，保留旧有序诊断为历史输出；优先复用原交点数据，不另建拟合代理。真实局部开口与完整评分区域资格仍待证据。
