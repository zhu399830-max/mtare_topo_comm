# 开口诊断读出：不确定碎片不再冒充多个实例

新增`aperture_diagnostic_readout.py`。把可能经unknown相连的几何分量组织为待确认集合；有支持但集合含多个分量时输出SUPPORTED_UNRESOLVED_COMPONENT_SET，不给实例数量。没有正支持不当成负例。支持计数必须与逐射线赋属一致；几何/观测冲突拒绝输出候选。

参考截面仅映射其种子中心点，不宣称整个截面已归属；所有可能相邻单元必须同属一个已知几何分量，未知/域外不按最近中心猜测。重复参考不会增加几何候选。该读出明确不是训练标签，也不报告完整实例数量。

## 下一步不再增加直管特例

当前24弯曲/坡道条件仍不支持；一般真实mesh同样不能靠两端点恒截面适配覆盖。下一实现通用原mesh的整单元范围检查：距全部表面足够远的球面单元，结合原网格内外/绕数，才能分类；接近任何面保留unknown。优先合成验证弯曲、变截面、内部重叠、分离层及有限边界，并测资源；不把最近三角面当联合边界、不改原mesh、不重渲染。通过后才只读原24例，仍不直接生成新教师或训练。
