# 双路口：先核对看见支路的射线，而非直接抄节点身份

独立模块gse_convex_ray_union.py把每个声明水平直管表示为有限凸64边形棱柱，半空间裁剪得到每条射线的入/出参数。只合并与传感器严格内点相连、且正长度相交的区间，遇到空隙停止；边界接触采取保守停止，不证明物理通行。没有调用生产mesh、SDF或teacher输出。

12个double_junction声明（3截面×4视点）的软件检查：在两个路口各沿支路轴线发射的测试射线均延伸到30米端面；从两路口中间朝侧面则先碰主管壁。这里测试射线不是已保存LiDAR束，更不能据此宣布每个实际视点都看清两个路口。

联合46项测试1.36秒通过，会话47132 exit0：区间排列、间隙、仅接触、原点未受支持、外部入射、平行miss、平移及曲线拒绝。首次4个圆角矩形测试将理想超椭圆半径2米误当数值64边形边界，误差约4.534e-7米；独立多边形边与水平轴求交确认后修改测试预期，仍使用绝对1e-12米，不修改原几何或松阈值。源码中没有自动修复sin/cos残差。

这只是可解释的几何射线工具，未读取扫描、输出新标签或训练。不能把它变成凭完整构造补隐藏支路的教师；没有射线见证不直接判不存在。下一只读原12双路口封存扫描，核对源绑定与每条实际射线的首次退出；记录有无穿过主管壁进入各支路的证据及其局部范围，再判断能支持哪些部分结构结论。旧结果及图片保持不变。
