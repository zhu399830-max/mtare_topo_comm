# 七条未知射线：实际三角面证据

exact_triangle_ray使用Python Fraction，对输入浮点坐标的精确数值计算平面交点及重心坐标，拒绝三角形外交点。它只检验提供的三角形，不是全网格求交器，也不能证明没有遗漏命中。三个解析软件测试通过。

check_unknown_hit_planes.py在已有Open3D环境实际运行，同7条未知射线50个原生命中，会话82008 exit0。圆形例5命中全部精确有效，其中两组是同operand、同平面、同精确交点；其余6椭圆例共有18命中在所报三角形之外，原float64及float32几何都如此。其余命中有效。详细精确分数、三角形编号、状态保存在[evidence](evidence/unknown_hit_planes_20260908.jsonl)。

这不等价于18条射线错误，也不证明Open3D整体错误。原生算法可能在极薄端盖面或近边界位置报告相邻面；必须检查三角形形状、越界幅度和邻面，不能直接删交点或按距离合并。未修改渲染器、原标签、阈值和历史结果。下一只定位这些端盖/邻接面是否存在合法交点。
