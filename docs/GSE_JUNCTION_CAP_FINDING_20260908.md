# 路口分支检查：哪些标签证据可信，哪些必须暂缓使用

## 结论

S04三种外形的同一路口均有三条数值稳定的端面进入分支；S07原路口只有一条稳定分支，另外两条全部落在原坐标与float32坐标包络的数值不确定区。因此，S07的问题不仅影响两个负归属，还影响原路口存在标签的这套证据。不能把原正标签默认当成不会出错的真值。

这不是模型失败，也不是证明S07没有路口。完整构造确实包含路口，但当前保存的观测证据尚不能按原三分支标准确认它。不得把完整地图答案直接替代缺少的观测支持。

## 做法与准确范围

只读已失败封存的 `gate3_20260908_gse_v8_original_ten_probe_v1r_seed20260906` 四观察前缀，2父地图、2物理穿越，4×5帧。核验原seal和原读取范围，重建原 .05m轴向、64角向端面；不调用标签生产器，不产生扫描或新标签，不读取C08–C10。

工具：`tools/v3/inspect_v8_junction_cap_geometry.py`。每条保存的进入见证必须对应原端面三角形、原返回前交点、原ROI。NumPy独立求解三角形交点，并通过原float64与float32逐坐标包络的向外舍入判别方向；不用人工选定距离容差。源方向先按原打包顺序归一化，不能多次归一化后改变原射线。

| 观察 | 三个界面的稳定进入射线数 | 方向未知射线数 | 稳定分支数 |
|---|---|---|---:|
| S04 mixed 36237 | 4124 / 3412 / 8090 | 0 / 0 / 0 | 3 |
| S04 ellipse 36237 | 4177 / 3295 / 7840 | 0 / 0 / 0 | 3 |
| S04 rounded_rectangle 36237 | 4166 / 4050 / 7626 | 0 / 0 / 0 | 3 |
| S07 rounded_rectangle 97000 | 6559 / 0 / 0 | 0 / 3435 / 1810 | 1 |

所有这些原float32交点在独立求解下都在相应三角形内部。方向不确定不是“射线没有打中”，而是原浮点表示变化足以改变入口前后判断。

S04开口1归属路口的保存射线3389 / 2925 / 2583条，全部同时有稳定路口端面进入见证，因此该步骤不必依赖尚未独立重算的侧面分支。S07开口0的665条有稳定端面支持，但路口三分支资格未满足；开口1的61条没有稳定端面支持。不能仅因665条存在就恢复整个S07路口标签。

## 有效结论与边界

- S04是一个父地图、一个物理路口的三种外形，不是三个独立成功实例。
- 这是部分参考标签的证据检查，不是完整背景、物理连通性、模型精度或建图收益证明。
- S07两条不确定分支没有保存的interior/lateral备选，不自动调用新的证明路径补过关。
- 原两次FAILED运行、旧标签和图片不变。未启动第三次教师批次或训练。
- 四观察工具实际退出0；相关区间、三角形、连续段和来源篡改20项测试通过，0.25秒。该测试数量不等于新工具有20个独立单元测试。

## 接下来只做一项修正

把源精度资格作为端面见证的显式非标签检查结果，先用合成边界路口确认：三条普通稳定分支通过；一条稳定、两条数值边界时不能认证三分支；已有字段和原结果不改。记录“保留旧正标签”只能用于确认有效的旧证据，不能强制保留已发现无依据的答案。

该合成修正通过后再决定新标签版本的具体受影响字段和范围；不继续反复检查同一四例，不直接扩展到全人口。若监督仍不支持完整检测评分，保持部分任务的结论边界，不能据此宣布正式A/B/C比较已就绪。
