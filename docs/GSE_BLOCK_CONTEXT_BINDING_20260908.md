# 块内形状与旧观测特征的共同接线

本轮新增`representation/gse_block_context.py`，只完成软件，不读取研究缓存、不运行编码器、不训练。

旧编码器每个五帧观察保存900个128维传感器特征。原始射线索引可以精确计算对应特征：帧索引乘180，加方位列整除4；同一方位组的不同仰角共享特征。这是原编码器分辨率，不是逐点独立学习特征。

新模块沿每个分块实际拥有的所有射线，按原始回波数量加权汇总这些冻结特征；块内点云形状由上一轮PointNet式模块另行保留。不再拿块中心的最近点特征代表整个块，不展开全人口逐点高维缓存。分批暂存最多2048×128的特征，最终输出每块128维旧观测信息。

软件要求原射线索引唯一、帧归属一致、回波有效、紧凑缓存有限，并复用既有ObservationBinding校验观察、五帧、输入SHA和编码器SHA一致。相同元数据本身不能证明文件真实性：实际加载时仍须核对封存字节。本轮没有声称已经完成真实45例缓存接线。

12项联合测试通过0.75秒：方位/仰角/帧边界、分批与完整汇总、点置换、错帧、重复索引、无效回波、非有限缓存、空输入及样本/输入/编码器版本漂移。

## 监督边界已按代码核对

`evaluation/gse_synthetic_field_scoring.py::expected_geometry`仅对限定合成观察提供锚点位置、开口位置/方向及该原型的完整性声明；范围边界的开口不是结构节点。宽高、根可达性、结构—开口成员关系不由该函数提供，不能从原型名字或最近锚点补成已知。

旧`data/gse_candidate_training_examples.py`仅构造旧候选锚点任务，不能直接当作新锚点＋开口训练器。旧失败头不重启，本轮不新增教师或更改历史评分。

下一步只读已封存的同45观察分块和紧凑缓存：先检验输入/帧/编码器来源一致、射线覆盖一致，完成实际绑定；不同投影实现的坐标不拿来做近邻身份匹配。通过后再登记结构输出、有效掩码与公平读出合同。仍未产生识别或建图收益。
