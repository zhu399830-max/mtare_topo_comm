# 修正扫描接入现有teacher：代码合同复核

本次只阅读现有代码与已报告转换统计，没有运行teacher、生成标签或训练。目标是把修正扫描接回已有研究链，而不是再造一套标签方法。

## 实际调用链

`gse_synthetic_matrix_execution.evaluate`先调用`diagnose_observation`，再调用V8联合目标生成器，最后独立评分。新导出仍是diagnostic bundle，不能仅重命名字段就宣称teacher输入资格已通过。

| 环节 | 代码实际做什么 | 仍需满足的条件 |
|---|---|---|
| 原始接口证据 | `gse_junction_interface_diagnostic_v1`校验五帧pose/来源，选10米范围内构造路口的接口，按已观测返回距离截断接口穿越；保留返回来源，不把穿越接口当返回来源 | 构造身份仅在teacher；原射线与新返回距离单位及存储精度兼容 |
| 内部支路证据 | `gse_interior_branch_evidence_v1`检查起点在同一候选结构至少三个不同方向的通道内部，再要求相应射线返回来源恰好为该单一通道 | 单一报告来源不等于已证明唯一来源；场的起点判定仍是既有0.025米采样场 |
| 侧向进入证据 | `gse_lateral_branch_evidence_v1`和`gse_observed_operand_entries_v1`检查返回前的入射表面交点、起点唯一归属、共同构造节点与方向；同样要求单一返回来源 | 新渲染器修正并未自动修改此原生接口证据路径；它查询表面交点，不重新调用旧union第一返回归约器 |
| 路口锚点 | `gse_reference_anchor_targets_v1/v3`汇合接口/内部/侧向证据，至少三个不同方向才给参考锚点；否则未知 | 锚点位置来自构造记录，不是由可见点估计出的真值；最多32，超限报错 |
| 局部开口 | `gse_reference_opening_targets_v1/v3`要求轴线参考归属、排他穿越与表面支持 | 是局部窗口参考截面，不是持久图节点；宽高仍为None；最多64 |
| 开口—锚点对应 | V8只使用进入且源表面支持的射线建立开口归属；departure可支持分支，但不能替代进入见证 | 竞争不唯一保留未知，不能按通道ID强行配对 |
| 评分背景 | anchor/opening目标均写明anchors_complete=false、openings_complete=false | 不能把未匹配预测全部处罚为假阳性，也不能把部分匹配成绩当完整检测F1 |

## 来源检查为什么必要

691200条返回中，77415条报告多个退出来源，613785条报告单一退出来源。前者被无损保留；后者还没有获得“所有其他通道都不可能贡献此表面”的独立证明。

现有代码中的`return_sources[i] == [source]`是实质性筛选条件。因此距离正确、codebook往返正确不能替代来源唯一性核验。当前没有发现这613785条全错或某个确定比例错误；不要把待验证风险写成已证实标签失败。

## 不是所有事情都要重新做

复用：五帧输入、相对运动、构造记录、接口射线方向检查、部分锚点/开口/对应输出和未知掩码。旧teacher与旧实验保持不变。

暂不做：重训模型、增加种子、重新渲染60帧、将开口参考截面当图节点、宣称完整背景或物理可达性。

下一工作收敛为同12观察的独立来源审计合同：固定“报告退出来源”和“唯一表面来源”各自的定义，依据同一原始声明的有限几何参考核对全部返回，而非读取模型输出；同时说明float32距离边界不确定时如何保留未知，不扩大数值容差。若来源满足现有teacher要求，再以同一V8实现做部分监督诊断；背景不完整的结论不因来源通过而改变。

是否继续训练还需要可评分目标人口、可靠背景/未知边界与统一方法对照，本次代码复核没有证明这些已完成。
