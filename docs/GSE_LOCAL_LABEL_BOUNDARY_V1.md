# 局部结构标签边界：不以整轴证据代替结构答案

2026-09-07。阶段3，软件与合成反例；不是新真实标签或模型实验。

## 已证实的接口局限

`test_gse_axis_proxy_semantic_boundary.py`三项反例通过：相同观测和相同局部轴线，仅延长远处参考就改变整轴支持结果；仅三条自由射线也能支持三个参考轴线，但没有提供开口轮廓、侧壁组合或终止面证据。因此现有轴线proxy只能解释射线覆盖，不能直接当语义教师。测试没有证明真实S08已经可标，也没有授权缩短轴线后补正标签。

## 标签必须回答的三个不同问题

1. 开口：当前五帧中哪里有可辨认的通道开口？位置与方向需要可见依据；看不清的宽高保持未知。窗口截面见证不能自动等同完整开口。
2. 锚点：当前观测是否支持一个稳定的路口或真实尽头位置？不能用机器人当前位置、窗口开口数量变化位置代替。只知道构造degree或看到三条射线不够。
3. 归属：哪些开口可以确认属于哪个锚点？逐对true/false/unknown，不强迫每个开口都有锚点，更不强迫唯一归属。

物理可通过性另有机器人合同要求，当前暂停。完整评分区域须单独确认，不能由空正例列表自动推出“背景全部完整”。真实人工复核没有发生前不得声称人工标签；自动标签也必须实现观测证据判据，而不是填一句evidence字符串。

## 已实现的可复用入口与下一步

旧21决策复核入口不适用当前单五帧人口。新增`data/gse_surface_review_v1.py`支持单观察、每点历史slot、独立锚点与开口，直接复用已实现的目标校验。先锁定盲看判断再显示单独构造参考，源帧与bundle哈希绑定；导出始终不自动授予训练资格，reviewer声明不被当成真实身份认证。合并目标校验/反例共22测试通过，真实导出与人工复核0。

下一步复用原浏览器点云旋转/XY/XZ展示实现当前单观察界面与独立开口编辑，再按已批准固定人口准备精确复核包。不得继续使用21步硬约束，不把旧开口嵌套规则偷偷带回新标签，也不启动第四次整轴诊断。人工判断是需要实际完成的标注工作，不是运行批准。
