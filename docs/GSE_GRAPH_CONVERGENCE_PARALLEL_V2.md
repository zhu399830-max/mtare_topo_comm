2026-09-05。用户在审阅收敛计划后明确要求加速、建立持续目标、多线并行并优先5090任务。本文与PLAN最新覆盖共同执行；不升级Phase3科学结论。

## 唯一研究主线

五帧激光 → 三维通道基元 → 局部结构及端口归属 → 在线拓扑图 → 探索。结构识别由学习完成，地点身份由检索/定位/配准联合验证，连接由真实连续运动确认。不得再要求局部描述子单独解决全局身份和连接。

核心候选贡献是：受控几何变化下保留结构关系、同时保留真实度量差异的组合学习，并证明它实际改善节点/端口与探索。一般GNN、基元拟合、域随机化、配准、轨迹建边和图共享均非独立创新。

直接近邻必须包含 Learning High-level Semantic-Relational Concepts for SLAM（IROS2024，https://arxiv.org/abs/2310.00401），其已有几何到高层概念学习及合成随机化。交通拓扑T2SG（CVPR2025，https://openaccess.thecvf.com/content/CVPR2025/html/Lv_T2SG_Traffic_Topology_Scene_Graph_for_Topology_Reasoning_in_Autonomous_CVPR_2025_paper.html）已有反事实机制，不能把同名术语包装为新贡献。

## 并行而非串行等待

1. GPU队列：先完成已具备几何监督的原C01同180观察/900帧/1452片段的raw-v-mean同预算对照；两分支同初始化/Adam.001/B1/540步/seed0，只有原坐标或token均值广播坐标不同。点数、mask、token特征不变；offset固定0。它不是旧900token decoder精确复现，初始参数相同但初始输出允许不同。独立training card/spec及测试通过后执行一次，不能复用历史offset训练授权。
2. 教师/组合关键线：核对原180节点级监督，区分通道裁剪端、构造端和当前区域端口。所有部署基元参与，教师不预筛incident；UNKNOWN不当负例，未知比例和支持数量完整报告。完成后直接做GT/预测基元同组合头、无相对组合、无配对一致性对照，不等待几何MAE全部达标。
3. 图软件线：复用因果内核，补持续端口更新，接入实际点云配准而非外部通过boolean；只做合成软件验证，不借此启动真实graph/闭环。

冻结骨干特征尽量单次导出复用，GPU物质实验串行，CPU标签/图/结果整理可并行。数据读取、教师生成和训练各自绑定准确card；未知数量先由最小授权元数据确定，不编造。新实验需源冻结；其他并行代码不得在正式run期间修改其哈希绑定源。

## 决定性实验与停止

GT基元也失败→检查监督/输入/实现；预测基元才失败→按漏检、位置、方向、截面、置信度替换定位；无组合版本同样有效→停止扩大组合；配对约束无收益→不作为贡献并重新评估；结构改善图不改善→检查图接口，不用planner掩盖。每个修正需具体已复现原因，不因结果差自动加轮数/换seed。

先180观察容量检查（事件macro-F1≥.95、端口F1≥.90，非泛化PASS），再独立父地图短训，再全量开发和seeds0/1/2。原最终标准保留：事件+5pp、局部几何MAE-10%、node/edgeF1各+5pp、合并P≥.99/R≥.60、三seed平均改善且至少2seed达主门。几何门是后续资格线，不再作为禁止早期受控结构实验的逻辑前提。
