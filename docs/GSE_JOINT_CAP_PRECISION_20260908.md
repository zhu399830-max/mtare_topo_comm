# 联合标签的进入、离开双向数值资格

## 完成内容

源区间模块和源绑定适配器现在显式支持entering/leaving两方向。原默认entering不变；离开判据要求整个源数值区间稳定向前且朝外，进入或边界射线不能冒充离开。

V8新增默认关闭的 `qualify_cap_precision`，明确传给路口生产器和V7负归属路径。后者重新核原扫描，分别过滤端面进入、离开候选，并保存两方向诊断；不能添加原来不存在的方向射线。内部/侧面路径未被替换。旧默认源码行为、旧封存运行不改写。

`check_gse_joint_lateral_v8.py` 在原四个实际CSG合成场景真实运行退出0，开启与关闭精度选项的record逐元素一致：
