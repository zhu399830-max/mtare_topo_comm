# 候选覆盖评分接口

实现 `src/mtare_topo/evaluation/gse_candidate_coverage.py`，复用既有几何一对一匹配，不改旧评分或旧运行。

目的：后续候选路线比较不能只报告“附近有没有一个候选”，必须同时公开候选数量、漏失、重复和三维位置误差。当前没有合格的三维候选器成绩，此接口不产生候选、更不接入模型前向。

固定报告1/2/4米，不选最好距离；全部候选计数，不按真值裁剪或按置信度挑选。分别报告最近候选覆盖与一对一召回，防止一个点冒充两个路口。背景标注不完整时只报告未匹配候选，不将其声明为误报或计算precision/F1。没有目标的召回、没有匹配的误差均为空，不填造满分或零误差。

8项软件测试通过（0.16秒）：重复撒点、候选合并两个结构、未知背景、空直道误检、空预测、上下层三维距离、共同刚体变换与排列、坐标系及非法输入。它们不是正式实验人口，也不证明候选召回或学习增益。

本轮新增真实观察、模型推理与训练均为0。下一步登记观察驱动候选的具体生成规则和同45封存合成观察的比较规格；目标只进入独立评分，不可用于产生候选。候选生成尚未实现，不能据软件通过启动筛选训练。原自由查询与旧偏移投票不重训；表示路线比较和最终建图收益目标不变。
