# 局部结构监督：原180观察的实际结果

2026-09-05，Phase 3。完成的是训练答案生成，不是结构模型训练成功。

## 做了什么

复用C01十个父地图的180个五帧观察、900个原始帧及1452个可见基元片段。生成器提供构造中心和成员关系；五帧回波在每条原生轴线上的支持区间决定哪些中心、成员和事件参与监督。不使用旧采样节点筛选答案，不重新生成地图或扫描。

V1因新程序漏复现旧float32位移保存格式而停止，失败记录不变。V1R只补保存转换，仍逐元素比较；新增非整数运动及单个最小存储单位漂移反例。对应源码版本为`256a059`和`b15f01b`。

## 得到什么

| 标签 | 观测中的有效次数 | 独立构造实例 |
|---|---:|---:|
| 有支持的局部中心 | 1206 | 304 |
| 完整支持的走廊事件 | 872 | 223 |
| 完整支持的交汇事件 | 14 | 6 |
| 有封闭表面证据的终点事件 | 0 | 0 |

中心最多13个/观察。成员标签为2155个正例、13510个负例；这是重复观察中的训练项，不能视为同等数量的独立样本。749个候选事件仍未知。25个观察出现非incident多来源歧义，受影响成员保留UNKNOWN；这不证明25个地方存在实际物理碰撞或错误连通。

全部旧几何、关系和相对运动按源存储合同复现通过。V1R用时11.306秒，峰值671420416字节，结果约13.16MB，零模型推理/训练/扫描重渲染。1152个实际来源文件哈希核对，35项结果seal复核；10张完整XY/XZ图、360个面板覆盖全部180行。

## 结论与下一步

可以进行中心与部分成员的接口拟合小实验，但不能用这批人口证明完整节点检测或三分类成功：交汇实例少、终点证据未接入，所有观察都不是完整负例标注。支持区间也是工程代理，不是完整可见性或物理连通证明。

下一步优先GPU小头：复用已冻结的全部32槽预测轴线，比较GT输入、固定预测输入、同预测去掉显式相对关系。只在loss侧对应GT与预测方向，非唯一对应保持未知；不能用教师mask筛预测输入。先实现精确缓存关联和方向桥，再独立冻结实际训练字段/分母/预算。不重复运行骨干，不扩大三seed，不把这些partial结果称完整主方法成功。原180只有mixed，尚不能做跨形状一致性消融。
