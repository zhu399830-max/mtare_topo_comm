## 实现

`gse_region_queries.py` 将全部 32 条预测轴线转成最多 64 个方向锚点。共享的 26,826 参数小头从每个锚点提出局部中心，再读取全部轴线的相对位置、夹角和高差，分别输出事件、存在分数和通道成员分数。同一次观察可保留多个结构，不再只有一个全局事件。

锚点不冒充真实开口，预测中心不来自教师。不存在 node/edge/primitive ID 输入，不拼接旧头的宽高或存在概率；数值退化的方向显式不支持，其候选位置仍保留。两条关系路径及相对位移投票均可关闭，参数数量不变；这个对照仍保留一元特征聚合，不叫“完全不组合”。

中心输出随共同 yaw 旋转，事件和成员分数保持；端点排列同时重排 query 与成员两个维度。中心使用等变向量基和相对位移投票，无向量坐标直接送任意 MLP。重力方向固定，不声称全 SO(3) 神经等变。

集合匹配只在损失端执行。教师到预测 token 的成员对应仍须另行提供给 loss，不能据此筛掉前向候选。未知不当背景，只有标签完整时才能处罚未匹配存在预测。缺少可用正成员且无已知中心/事件的目标不能产生存在正例。输出有效监督数、不可支持/未确认目标数和未匹配目标数；`matched` 是算法分配数，不是识别正确数。

当前软件损失包含中心欧氏误差（沿用50米尺度）、事件、成员、存在及未校准事件错误不确定性；匹配代价包含同样的任务项、完整标签下的背景代价差与固定 batch 分母。其权重尚未作为真实训练规格冻结，不宣称已完成校准或最佳损失选择。

## 已修正的反例

- 唯一已知成员落在不支持 token 上时，旧实现仍产生存在正例；现计为未匹配。
- 中心完全相同但存在分数不同的候选，旧匹配只看几何，换数组顺序会改变总损失；现匹配包含实际存在代价。
- 极短轴线数值支持曾用最大坐标分量，旋转45度会改变判定；现用欧氏半径，并补完整轴线桥到小头的旋转回归。浮点临界判定仍只是数值保护，不是可见性指标。
- 只有负成员标签并不足以证明区域存在；无其他有效依据时保留未确认状态，不生成存在正例。
