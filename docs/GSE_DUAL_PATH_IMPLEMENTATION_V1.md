## 固定路线与对照

固定128维、两层集合注意力、四头，最多32基元/32结构查询/64开口查询。输出LocalStructureObservationV2含来源帧、坐标系、顺序或时间、实例/开口的位置与概率、归属和未知字段。存在性与事件分别记录，事件评分包含未检出；未知不是背景。教师仅loss/评分。几何缺失或置信度低不能关闭观测旁路。

A只有观测到结构；B新增几何辅助监督但不读取预测几何组合；C同时使用几何监督和组合通路。结构loss必须在A/B/C共享点级适配层有梯度，B的几何loss也须作用同一共享适配层，否则B不是几何辅助对照。参数布局和初始化一致；共同预训练不等于A从未见几何监督。首轮冻结旧编码器，只训练新增点级适配/薄几何/结构模块；不加跨变体一致性损失。非学习几何、出口和真值参考使用同后端。
