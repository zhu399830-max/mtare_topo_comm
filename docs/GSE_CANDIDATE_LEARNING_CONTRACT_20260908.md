# 候选学习损失与评分合同（合成拟合诊断）

八邻居按观测候选三维距离生成，等距使用已封存来源顺序；这是信息交换关系而非通道连接。法向未知时关系valid为0，射线自由/障碍/未知保持0/0/1。没有教师或模型分数筛选邻居；本生成器不声称等距截断在任意重新编号下不变。

训练输出解释为局部结构支持分数，不是校准后的节点存在概率。目标为 `max(1 - 最近真实锚点距离/1m, 0)`，重复位置得到相同答案；禁止把几乎相同候选任意分为一正一负。真实位置只用于目标构造和独立评分。正支持组和确定背景组分别平均BCE，再平均非空组，防止数万背景项吞没稀少正支持；记录两组有效数量。未知背景不进损失。

输出合同：固定分数≥0.5，按分数降序、三维位置及来源索引处理；固定1米贪心抑制，保留原始选择、保留索引、每个被抑制项及抑制者。1/2/4米几何一对一评分同时报告抑制前后，不能只公布有利结果。该规则会漏掉近邻两个真实节点；测试明确保留这一失败。这里只服务45观察合成拟合，不适合作为已经合格的全局节点合并规则。
