# 有限纠错的软件实现：训练匹配与窗口开口

本次未运行新训练，没有改变v2分数。新增独立模型/损失版本，旧类和旧损失保持不变。

## 固定修正

- 开口：原三维位置读出改作方向参数，归一化到固定10米窗口球面；没有增加参数，锚点仍独立预测三维位置。
- 训练匹配：`距离/10米 - 存在概率`，一对一Hungarian分配。类别代价只参与训练；独立评分仍几何匹配，不能借训练分配计算F1。
- 存在性：正例权重1、无目标权重0.1，按有效权重和归一化，分别记录原有效样本数。数值预先固定，不搜索多个权重挑结果。
- 开口负监督：仅明确完整窗口中的未匹配查询参与，不再依据预测半径决定是否处罚；未知窗口仍只监督已知正例。
- 范围：当前版本仅处理锚点、开口和方向。任何已知尺寸/可达/归属输入会拒绝，而非默默丢弃。这对应现有独立合成oracle，不授权用它替代真实多任务训练。

参考成熟集合检测的类别+几何训练分配与no-object处理，依据见GSE_QUERY_DOMAIN_DIAGNOSIS_20260908.md；不作为论文创新。修正域和损失是两个因素，之后必须分开解释，不能把整体修复收益归功于几何关系。

## 已验证与尚未验证

新损失、球面域及旧损失联合31测试通过1.29秒；修正有效权重归一化分母后新模块7测试再通过0.92秒。测试证明训练分配响应置信度、客观几何评分不变，完整窗口64查询都有正确方向的存在性梯度，未知未匹配没有梯度，域外预测直接拒绝不静默丢弃。

初次2测试因float32标签提升为float64后仍要求float64球面精度而失败。已让测试按正式float32执行，没有修改球面容差或标签数值。
