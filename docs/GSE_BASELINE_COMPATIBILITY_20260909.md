# 现成非学习基线与当前任务的接口差异

本次只读代码，不运行数据或产生新模型结果。目的不是取消对照，而是防止把不同任务的输出伪装成同一成绩。

| 已有模块 | 实际输入/输出 | 可保留用途 | 不可直接做的比较 |
|---|---|---|---|
| `RangeExitBaseline` | 当前距离图、有效掩码、仰角；水平长距离扇区和方位角 | 机器人视点下的局部出口参考、旧出口基线 | 没有持久路口三维位置，不是远处路口各支路的三维切向 |
| `RobustPrimitiveRelationBaseline` | 五帧归一化到50米的16×720扫描、相对平移/yaw；三点扫掠轴线、截面、端点关系 | 旧几何拟合及其失败分析，复用观测配准和截面估计代码 | 裁剪轴端点不能当路口；自动attachment不能当物理连接证明 |
| `nonlearning_geometry_observation` | 五帧扫描；规则事件、单轴、宽高、出口token | 旧规则语义消融 | 不预测独立节点位置；端口上限6、confidence=1和uncertainty=0是规则值，不是校准结果 |
| `gse_exit_only_baseline` | M1D三类角色概率映射到旧五事件类别 | 原事件任务的公平映射 | 不是三维节点/支路集合预测器 |

## 具体阻止直接接线的代码证据

`primitive_relation_nonlearning.py` 的 `predict` 中，`both_ego_stubs` 为真时，无论端点距离如何，`if both_ego_stubs or ...` 都会建立attachment。两个非双向候选近机器人端点被指定为相连。它表达旧基线的局部根连接假设，而非从独立证据确认两个端点属于同一路口。因此对分层或同窗口多路口不能当可靠语义归属参考。

该模块还会在无长距离扇区时强制产生一个最强列候选，在支持不足时补取最近点，并将不足的轴长扩到固定最小值。这些可以作为公开旧基线的假设报告，但不能把补出的几何标为有观测支持的训练真值。当前超点实验使用10米ROI，旧模块默认50米扫描；不加说明直接运行，会增加输入范围。

## 采用的决定

1. 历史实现、权重、成绩与图片不改，不将旧分数搬进当前307部分路口评分表。
2. 不给非学习方法教师节点、教师端口或教师筛选候选；不把机器人位置当远处真实路口，也不把所有未知输出填零后宣称同接口。
3. 当前R0/R1/R2比较已经是同输入学习表示诊断，仍缺少同任务非学习节点/支路输出。明确记录缺口，不虚构已完成对照。
4. 下一步复用几何拟合组件，先设计并用合成场景检验**由独立观测轴线提出交汇位置**的公共几何适配。候选位置必须由轴线空间关系产生，不能由教师产生；平行、分层、不相交、无支持必须允许拒绝。该适配是新增非学习比较方法，须新版本说明，不冒充旧基线原样复现。
5. 在适配合同及合成反例成立前，不启动307真实基线运行。真实运行仍要绑定准确输入范围和预算，保留无输出失败，不能用补全规则躲避失败。

这一步不解决学习方法的误报，也不宣布路线胜出。用途是把缺失对照补成真正可比较的方法，而不是用错误基线衬托学习结果。
