# 尽头观测证据：端面返回核对

旧 `gse_supported_construction_teacher.py` 明确没有实现端面返回检查，因而把所有尽头事件保持未知。本次补齐其中的几何对应部分，不更改旧标签和旧运行。

`gse_cap_return_evidence_v1.py` 从原始扫掠网格的明确三角面布局绑定起点、终点端面。采用原生成器的 0.05 米轴向采样、64 个角向分段完成合成来源兼容测试；不把任意局部截面当端面。

逐射线检查：射线必须有效、因果；与端面三角形内部交点距离必须匹配首返回，误差仅来自保存精度、数值计算及调用方明确绑定的测距误差。返回在端面前或端面后均不能充当端面见证。三角边界接触单列歧义；记录射线、三角面和来源帧。

7项新测试及已有局部证据回归共29项通过，包括实际网格生成器双端绑定、改写三角面拒绝、前景遮挡、远墙返回、无返回、三角边界和未来帧。全部为合成软件检查；新真实标签0、训练0。

## 尚需接线

端面返回不是完整尽头标签：还需核对该端点确实属于单支终止构造，以及返回来自整体并集的外表面而非重叠通道内表面。该步骤必须使用原始来源证据，不能用模型分数、裁切边界或缺少穿越射线代替。接口因此暂不输出 terminal 标签、不授予训练资格。

下一步把端点构造归属及现有首返回来源绑定到该检查，再纳入同一30观察诊断。此处不声称已解决路口分支标签、不声称真实标签人口达标。

## 单支端点与回波来源已接通

新增 `gse_terminal_reference_v1.py`，验证全部端点归属后，只对degree-one原始端点核对端面返回。回波来源集合必须唯一且对应该基元；多来源或其他来源不强行分配。degree-two构造分段不产生尽头。输出仍为部分自动参考证据，不声称周围结构完整、不产生训练资格；真实数据适配必须先经过原SurfaceTeacherReader来源验证。

4项新增测试与端面组件共11项通过：可见单支端面获得参考支持、普通分段不产生尽头、多来源拒绝、重复端点归属拒绝。无真实数据读取、无新训练标签、无训练。下一项将此函数接入原五帧bundle并冻结同30诊断，报告实际可见端点人口，而非继续把纯软件通过当结果。
