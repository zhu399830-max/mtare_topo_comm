# 路口生产器显式端面资格选项

已在anchor V3添加 `qualify_cap_precision=False`，默认旧行为不变。显式开启时，内部基础生产器根据原bundle/raw重新计算源绑定资格，只允许删去未资格的端面进入见证，不允许注入外部伪造的合格射线；记录实际采用的端面见证及精度审计。内部/侧面见证仍独立参与分支支持，不受端面未知一票否决。

27项相关单元测试通过，0.86秒。新增接线测试验证：旧三支在两支被判不稳定后不生成锚点；真实调用者提供的内部或侧面见证仍能支持三支；资格结果不能添加原来不存在的射线。此测试用替身隔离接线，不冒充真实几何判断。

此外真实合成CSG五帧代码路径三场景执行通过：

| 输入 | 只用合格端面生成锚点 | 加内部/侧面后生成锚点 |
|---|---:|---:|
| 源内部无端面进入 | 0 | 1 |
| 明确三方向端面穿越 | 1 | 1 |
| 恰在端面且无足够分支 | 0 | 0 |

三个场景开启与关闭选项的record完全一致，说明这些稳定/合法内部案例没有因新检查退化；不能用此声称S07错误标签已经在整条联合生产链中修复。输入raw未变，原来源身份篡改拒绝。
